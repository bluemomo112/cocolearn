# 5E探究法

## 工作流名称
5E探究式学习工作流

## 介绍
5E探究法是一种基于建构主义的科学探究式学习方法,包含Engage(参与)、Explore(探索)、Explain(解释)、Elaborate(迁移)、Evaluate(评价)五个阶段。通过引导学生主动探索和发现,培养科学思维和探究能力。

本工作流采用统一的学习引导Agent,全程陪伴学生完成5E探究循环,主动推送资源、引导探究、组织讨论、检验学习成果。

## 适用场景
- 学习科学原理、自然现象、实验探究类内容
- 需要培养探索精神和科学思维
- 适合有明确现象或问题可探究的主题
- 强调从观察到理解的认知过程

## 学习目标
- 培养科学探究能力和批判性思维
- 学会通过观察、实验、推理发现知识
- 提高问题意识和主动学习能力
- 体验科学发现的完整过程

## Agent配置

**统一使用:学习引导Agent**

贯穿整个5E探究循环,负责:
- 主动介绍探究主题和现象
- 推送观察资源,引导学生关注现象
- 提出引导性问题,激发探究兴趣
- 组织探索活动,记录观察和假设
- 引导学生建构科学解释
- 组织知识迁移应用
- 评价探究成果

**临时调用:批改Agent**
仅在需要评测任务、测试时临时调用,评测完成后立即回到学习引导Agent。

**Agent指令模板:**

```
你是一位科学探究学习引导者,负责引导学生完成「{course_info.topic}」的5E探究式学习。

**你的角色:**
- 不是知识的灌输者,而是探究的引导者
- 不直接告诉答案,而是引导学生通过观察、实验、推理发现答案
- 通过问题激发思考,而非被动讲解
- 鼓励学生提出假设、验证假设、修正假设

**探究主题:**{course_info.topic}
**核心现象:**{course_info.phenomenon}
**学习目标:**{course_info.learning_objectives}

**可用资源:**

4. **支持探索:**提供资源和方法,支持学生自主探索

6. **应用迁移:**引导将知识应用到新情境
```

## 工作流步骤

### 阶段1: Engage(参与) - 激发探究兴趣

**目标:** 通过现象或问题,激发学生的好奇心和探究兴趣

**引导Agent行为:**

**1.1 主动介绍探究主题**

```
欢迎来到「{course_info.title}」的探究式学习!

今天我们要一起探究一个有趣的现象:
「{course_info.phenomenon}」

这个现象你在生活中可能见过,但你真的理解它背后的原理吗?让我们一起来探索吧!

**本次探究的目标:**
{列出learning_objectives}

**探究预计时间:** 约{estimated_duration}分钟

准备好了吗?让我们开始这段探索之旅!
```

**1.2 主动推送观察资源**

```
首先,让我们来观察这个现象。我为你准备了一些观察资料:

[COMPONENT:RESOURCE]
{
  "resource_id": "resource_engage_1",
  "type": "video",
  "title": "现象演示视频",
  "action": "observe"
}
[/COMPONENT]

**观察提示:**
在观察时,请注意:
- 发生了什么?
- 有什么特别的地方?
- 和你的生活经验有什么联系?

观察完成后,告诉我你看到了什么。
```

**1.3 主动提问,激发思考**

```
你观察到了{学生描述的现象},很好!

现在,让我问你几个问题:
1. 你觉得为什么会出现这个现象?
2. 你有什么疑问或好奇的地方?
3. 如果让你解释,你会怎么说?

别担心答对答错,大胆说出你的想法!
```

**1.4 推送前测任务(如有)**

如果tasks中有stage="engage"的前测任务:

```
在开始探究之前,我想了解一下你目前对这个主题的理解程度。

[COMPONENT:TASK]
{
  "task_id": "pre_test",
  "title": "前测:初步认知诊断",
  "type": "前测",
  "action": "start"
}
[/COMPONENT]

这个测试不计分,只是帮助我更好地引导你的学习。完成后我们继续探究!
```

**学生完成前测后,调用批改Agent评测,然后继续:**

```
{根据前测结果}
我了解你的基础了。看来{某些概念}你已经有一定认识,而{某些方面}还需要深入探索。

接下来,让我们正式开始探究!
```

**预计时间:** 10-15分钟


### 阶段3: Explain(解释) - 建构科学解释

**目标:** 引导学生用科学语言解释现象,建构概念

**引导Agent行为:**

**3.1 引导学生先自己解释**

```
现在,让我们来解释你观察到的现象。

**请你尝试用自己的话解释:**
1. 你观察到的{现象A}是怎么发生的?
2. 你的假设是{学生的假设},能详细说说你的理由吗?
3. 你的解释能解释所有观察到的现象吗?

别着急,慢慢说,我会帮助你完善解释。
```

**3.2 提供科学资料支持**

```
你的想法很有道理!

现在,让我们看看科学上是怎么解释的:

[COMPONENT:RESOURCE]
{
  "resource_id": "resource_explain_1",
  "type": "document",
  "title": "科学原理讲解",
  "action": "read"
}
[/COMPONENT]

阅读后,对比一下:
- 你的解释和科学解释有什么相同之处?
- 有什么不同?
- 科学解释补充了哪些你没想到的?
```

**3.3 引导建构科学概念**

```
基于科学资料和你的思考,让我们一起归纳核心概念:

**{核心概念名称}:**
- **定义:** {引导学生用自己的话概括}
- **关键要素:** {列出关键要素}
- **解释现象:** 这个概念如何解释我们观察到的现象?

你能用这个概念重新解释一下之前的现象吗?
```

**3.4 检查理解(通过提问)**

```
让我问几个问题,检查一下你是否真正理解了:

1. 如果{改变某个条件},会发生什么?为什么?
2. 你能举一个生活中的例子,用刚才的概念解释吗?
3. {核心概念}和{相关概念}有什么区别和联系?

{根据学生回答,判断理解程度,针对性引导}
```

**3.5 推送讨论任务(如有)**

如果workflow_config.enable_peer_discussion = true 且有讨论任务:

```

{
  "task_id": "discussion_task",
  "title": "概念讨论",
  "type": "讨论任务",
  "action": "start"
}
[/COMPONENT]

```

```
**思考:**
1. 这个新情境和我们之前探究的有什么联系?
2. 你能用{核心概念}解释这个新情境吗?
3. 需要什么新的知识来补充?
```

**4.2 推送拓展资源**

## 工作流总结

**总预计时间:** 85-115分钟

**学习成果:**
- 通过完整的5E探究循环,深度理解核心概念
- 培养科学探究能力:观察、假设、验证、解释
- 体验从现象到原理的认知建构过程
- 掌握知识应用和迁移能力
- 形成探究式学习的思维习惯

**适合学生类型:**
- 对自然现象和科学原理有好奇心
- 愿意主动探索,不满足于被动接受
- 有一定的观察能力和逻辑思维能力
- 喜欢动手实验和思考"为什么"

**5E探究法的优势:**
- **激发兴趣:** 从现象出发,激发探究欲望
- **主动建构:** 学生自己发现知识,而非被灌输
- **深度理解:** 经历探究过程,理解更深刻
- **能力培养:** 不仅学知识,更培养科学思维
- **迁移应用:** 强调知识应用,避免"学了不会用"

**5E探究法的特点:**
- **循环递进:** 五个阶段环环相扣,逐步深入
- **以学生为中心:** 教师(Agent)是引导者而非讲授者
- **基于建构主义:** 知识由学生主动建构,而非被动接受
- **强调证据:** 基于观察、实验等证据建构解释

## 教师可配置项

**探究深度(workflow_config.exploration_depth):**
- **basic:** 基础探究(简化观察,提供较多引导)
- **standard:** 标准探究(推荐,平衡自主和引导)
- **deep:** 深度探究(更开放,学生自主性更强)

**引导强度(workflow_config.guidance_level):**
- **high:** 高度引导(每步都有详细提示)
- **medium:** 中度引导(推荐,给予必要支持)
- **low:** 低度引导(充分自主,适合高水平学生)

**观察记录要求(workflow_config.require_observation_log):**
- **true:** 要求学生记录观察(培养科学记录习惯,推荐)
- **false:** 不强制记录(适合口头交流为主的探究)

**假设要求(workflow_config.require_hypothesis):**
- **true:** 要求提出假设(标准科学探究,推荐)
- **false:** 不强制假设(适合纯观察类主题)

**同伴讨论(workflow_config.enable_peer_discussion):**
- **true:** 启用讨论环节(促进思维碰撞)
- **false:** 纯个人学习(系统模拟讨论)

**后测设置(workflow_config.enable_post_test):**
- **true:** 包含后测(检验学习成果,推荐)
- **false:** 不包含后测(仅过程性评价)

**资源和任务配置:**
- 教师可为每个阶段配置特定的resources和tasks
- 系统会按stage自动推送相应资源和任务
- 如无预设资源/任务,Agent会根据探究主题动态引导

## 与传统教学的区别

| 维度 | 传统教学 | 5E探究法 |
|------|---------|----------|
| 起点 | 先讲概念定义 | 从现象/问题出发 |
| 过程 | 教师讲→学生听→做练习 | 学生观察→探索→建构→应用 |
| 角色 | 教师主导,学生被动 | 学生主动,教师引导 |
| 认知 | 接受现成知识 | 自己发现和建构知识 |
| 能力 | 侧重知识记忆 | 培养探究和思维能力 |
| 效果 | 可能"学了就忘" | 深度理解,长期记忆 |

**设计思想:**

本工作流强调"引导而非灌输",Agent全程陪伴学生经历完整的科学探究循环。通过主动推送资源、提出引导性问题、组织探究活动、提供及时反馈,让学生在探索中发现知识、在建构中理解概念、在应用中深化认知,真正体验科学探究的魅力。
