# 麦肯锡空雨伞

## 模板说明
麦肯锡空雨伞框架是一种结构化思考方法，通过"空(现状)→雨(原因)→伞(解决方案)"三步，帮助清晰分析问题和制定行动方案。

## 适用场景
- 案例分析
- 问题解决型学习
- 批判性思考训练
- 需要提出解决方案的场景

## 三个部分的含义

### 1. 空(Sky) - 现状是什么？
- 客观描述当前情况
- 收集相关事实和数据
- 明确问题所在
- 回答："发生了什么？"

### 2. 雨(Rain) - 为什么会这样？
- 分析问题的原因
- 探究深层次的根源
- 找出因果关系
- 回答："为什么会这样？"

### 3. 伞(Umbrella) - 应该怎么做？
- 提出解决方案
- 制定具体行动计划
- 预测可能的结果
- 回答："我们应该做什么？"

## 使用建议

1. **按顺序思考**：先观察现状，再分析原因，最后提出方案
2. **保持客观**：在"空"的部分，尽量用事实和数据说话
3. **深入分析**：在"雨"的部分，不要停留在表面原因，要挖掘深层原因
4. **具体可行**：在"伞"的部分，方案要具体、可执行，避免空泛
5. **完整闭环**：确保"伞"中的方案能够解决"空"中提出的问题
