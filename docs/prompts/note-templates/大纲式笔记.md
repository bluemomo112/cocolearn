# 大纲式笔记

## 模板说明
大纲式笔记使用层级结构组织信息，通过主题、章节、知识点的层级关系，清晰呈现内容的逻辑框架。适合结构化的学习内容。

## 适用场景
- 教材章节学习
- 长文阅读笔记
- 系统性知识整理
- 需要建立知识框架的内容

## 使用建议

1. **先搭框架**：开始学习前，先根据资料目录搭建大纲框架
2. **逐层填充**：学习过程中，逐步填充各级内容
3. **保持层级**：一般使用2-4级标题，不要过度细分
4. **适度展开**：每个知识点不必过分详细，重点是建立清晰的结构
5. **标注重点**：用**加粗**、*斜体*或颜色标记重要内容
6. **补充关联**：在学完后，补充知识点之间的关联关系

## 层级结构说明

- **一级标题(#)**：主题名称
- **二级标题(##)**：大章节/部分
- **三级标题(###)**：小节/知识点
- **四级标题(####)**：子知识点(可选)
- **列表**：具体要点、示例
