# **LMS-教师端-创课流程 (设计完成,待开发)**

**⚠️ 实现状态: 🔲 待开发**

**3. 功能详细说明**

**\*为强制输入，否则则可以跳过。基础选项默认展开，高级选项默认收起**

**总体交互原则：**

* **必填项控制：** 带 `*` 为必填项，未完成无法进入下一步；无 `*` 项可跳过。
* **折叠策略：** 【基础选项】默认展开，【高级选项】默认收起。
* **导航结构：** 分步式向导 (Step 1 -> Step 2 -> Step 3)。

---

**Step 1: 基础设置 (Basic Settings)**

> **目标：** 确立课程基本信息与核心知识库。

**1. 基础信息 (Basic Options)**

* **\****课程名称 (Course Title)* \*\*

  * **交互：** 用户输入文本。
  * **触发器：** 输入完成后（onBlur 或 停顿），AI 自动根据语义生成并推荐封面图。
* **\****相关学科 (Subject Tags)* \*\*
* **交互：** 标签选择/输入（如：物理、历史）。
* **作用：** 影响后续 AI 解析资料时的学科倾向和术语偏好。
* **\****课程资源配置 (Resource Configuration)* \*\*
* **约束：** 必须至少包含一个有效资源。
* **每个资源的属性：** 包含一个“学生可见性”开关（默认：可见）。
* **资源来源支持：**
* **关联知识库 (Knowledge Base)：** 从已预处理的向量库文件夹列表中选择。
* **自主上传 (Custom Upload)：** 支持多文件上传（PPT/PDF/Video/Web/Docx 等）。**文件状态流转：[上传中] -> [解析中(Embedding)] -> [就绪]。 ****A**

**2. 高级配置 (Advanced Options)**

*本模块包含“跨学科概念”与“课程目标”两部分，交互逻辑一致。*

* **跨学科概念 (Interdisciplinary Concepts)**
  * **手动输入：** 用户可手动键入多个标签。
  * **AI 智能衍生 (The Magic Sparkle)：**
    * **触发机制：**当挂载资源状态变为\*\*[就绪]\*\*后触发且挂载资源（Step 1 中上传的文件）含有相关信息时触发，若用户在[解析中]尝试操作，提示“AI正在阅读资料，请稍候...”；若未能提取出相关信息则提示“暂无未提取到相关内容）。但是所有这些操作都不会卡住用户操作（用户仍然可以手动输入）
    * **交互表现：** 在输入框下方展开 **[建议面板]。**
    * **文案示例：** “检测到该资料包含 5 个跨学科概念，是否写入课程元数据？”
    * **操作：** 提供【是】/【否】按钮。用户点击【是】（或按 Tab 键），AI 建议内容自动**追加**至输入框中。
    * **逻辑：** 智能衍生与手动输入不冲突，两者为并集关系。
* **课程目标 (Course Objectives)**
* **逻辑：** 同上（支持手动输入 + AI 内容嗅探推荐）。

---

**Step 2: 任务与评价配置 (Tasks & Assessment)**

> **目标：** 定义学习路径中的关键节点与考核标准。支持追加多个任务。

**1. 任务基础定义**

* **任务类型 (Task Type)：** 下拉选择（问答 / 单选 / 多选 / 文件提交 / H5 互动 Lab / 智能体交互）。
* **任务名称 (Task Name)：** 文本输入。
* **任务描述 (Description)：** 富文本输入。
* **必做状态 (Required Requirement)：** 开关（默认关闭）。
  * **学生端影响：** 开启后，必须完成此任务才视为“结课”。
  * **教师端影响：** 在教学监控墙（Dashboard）上，该任务将通过状态指示灯（红/绿）直观显示学生完成情况。

**2. 评价与反馈配置**

* **AI 辅助批改 (AI Grading)：** 开关【是/否】。
  * **结果推送：** 若开启，显示子选项“是否自动向学生推送批改结果”（开关）。
* **评价量规 (Assessment Rubrics)：**
* **自定义模式：** 提供文本框，允许用户输入具体的评分标准。
* **AI 托管模式：** 若用户留空，AI 将根据课程内容和任务描述，自动生成评分标准并执行批改。

**3.小组合作作业**

**该开关**仅在跟随模式起作用，打开后，学生界面将多一个选择自己是哪个小组的选项（可修改）。合作作业中，任何一个成员提交了这个作业，都视为全组的作业。保存历史提交版本，但是以最后提交的作业为latest version进行给分，**教师默认批改最新版，但**可选择回溯\*\*并基于任一历史版本打分。**（仅在教师端生效，学生的个人界面内容不受任何修改）。成绩也是全组统一成绩。**

* **是否小组合作作业：**开关【是/否】，默认为否
* **组数设置：int【1-20】之间的一个数字**
* **小组人数：int：1-10之间的一个数字**

---

**Step 3: AI 智能体配置 (AI Agent Configuration)**

> **目标：** 定制化“AI 助教”的行为模式与知识边界。此步骤允许教师进行 Prompt 注入与测试。

**1. 场景化智能体模板 (Agent Templates)**

* **配置项 1：默认跟随模式 (Follow Mode)**
  * *场景：课堂授课或实时引导。*
  * **选择模板：** 苏格拉底（引导式）/ 直白型（问答式）/ 鼓励型（陪伴式）/ **[绑定自定义智能体]。**
* **配置项 2：默认自学模式 (Self-Study Mode)**
* *场景：学生课后复习或自主探索。*
* **选择模板：** 选项同上。

**2. 高级个性化配置 (Advanced Customization)**

* **个性化提示词 (System Prompt Injection)：**

  * **针对选定的智能体，允许追加额外的 System Prompt（如：“请用海盗的口吻说话”）。**
* **知识边界控制 (Knowledge Boundary)：**
* **Strict (仅限课程资源)：** AI 仅基于 Step 1 上传的文件和关联 KB 回答，严禁幻觉，无答案时回答“不知道”。
* **Open (允许外部知识)：** 允许调用通用大模型知识库，但必须在回答中通过脚注标注信息来源。
* **沙箱测试 (Playground)：**
* **提供【测试】按钮。点击后弹窗/展开右侧面板，允许教师基于当前配置（知识库 + Prompt）与智能体进行模拟对话，验证效果。**

**3.2 模式一：跟随模式 (Synchronous Mode)**

* **操作****：点击中间底部的 ****【同步/推送】** 按钮。
* **数据流****：发送 WebSocket 指令 **`{ action: "push_resource", resource_id: "xxx", type: "video/ppt/quiz" }`。

**3.2.2 互动闭环 (中间主舞台的多态性)**

* **状态 B：结果视图 (Dashboard)**

## **项目实现总结与下一步计划**

  - 知识库系统
  - 认证和权限系统
  - 数据持久化

### **技术债务 (Technical Debt)**

1. **数据持久化**
   - **当前**: 内存存储 (Map 结构)
   - **问题**: 服务器重启后数据丢失,不支持多用户并发
   - **建议**: 集成 PostgreSQL + Prisma ORM

2. **认证系统**
   - **当前**: 无正式认证,使用临时 sessionId
   - **问题**: 无法区分真实用户,无权限控制
   - **建议**: 集成 NextAuth.js 或 Clerk

3. **实时通信**
   - **当前**: HTTP 轮询
   - **问题**: 跟随模式需要 WebSocket 实时同步
   - **建议**: 集成 Socket.io 或 Pusher

4. **文件存储**
   - **当前**: 本地文件系统
   - **问题**: 不适合生产环境,无法扩展
   - **建议**: 集成 AWS S3 或 Vercel Blob

5. **向量数据库**
   - **当前**: 无向量存储
   - **问题**: 知识库系统需要语义检索
   - **建议**: 集成 Pinecone 或 Supabase Vector

### **风险评估 (Risk Assessment)**

**技术风险**:
1. **AI API 稳定性**: 依赖第三方 API,可能出现限流或故障

   - **缓解**: 使用成熟的实时通信服务 (Pusher)
   
3. **数据迁移**: 从内存存储迁移到数据库
   - **缓解**: 编写迁移脚本,充分测试

**业务风险**:
1. **用户接受度**: 教师和学生是否愿意使用
   - **缓解**: 进行用户测试,收集反馈
   
2. **内容质量**: AI 生成内容的准确性
   - **缓解**: 人工审核机制,持续优化 Prompt
