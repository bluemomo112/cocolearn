## 五、动画规范

### 1. 过渡效果

```css
/* 标准过渡 */
transition-all duration-300

/* 苹果风格过渡 */
.apple-transition {
  transition: all 0.3s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}

/* 弹簧效果 */
.apple-spring {
  transition: all 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275);
}
```

### 2. 预设动画类

| 类名                   | 效果         |
| ---------------------- | ------------ |
| `animate-fade-in`    | 淡入         |
| `animate-fade-in-up` | 从下向上淡入 |
| `animate-slide-in`   | 从左滑入     |
| `animate-scale-in`   | 缩放淡入     |
| `animate-float`      | 浮动效果     |
| `animate-pulse-slow` | 慢速脉冲     |

### 3. 交互动画

```jsx
{/* hover 放大 */}
className="hover:scale-105 transition-transform duration-300"

{/* hover 上移 */}
className="hover:-translate-y-1 transition-transform duration-300"

{/* 点击缩小 */}
className="active:scale-95"
```

## 十、设计原则总结

1. **绿色主题** - 以 Emerald (#10b981) 为主色，象征学习与成长
2. **大圆角** - 采用 `rounded-2xl` / `rounded-3xl` 营造现代柔和感
3. **微动画** - 所有交互元素都有过渡效果 (`transition-all duration-300`)
4. **层次感** - 多层阴影 + 背景装饰营造空间深度
5. **留白** - 充足的 padding 和 gap，保持呼吸感
6. **一致性** - 统一的颜色、圆角、间距系统
