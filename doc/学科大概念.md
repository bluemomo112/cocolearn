| 学科大概念 | 学科大概念是在事实基础上的抽象概括，是深层次的、可迁移 的概念，是对概念之间关系的表述，涵盖学科内外知识体系的纵向与横向关联，保持学科内容知识的一致性和外部表现的多元性，体现学科内容知识与结构之有效概括力、包容力和解释力的上位概念。学科大概念是指向学科核心内容和教学核心任务，能将学科核心理念和知识内容有机联系起来的关键概念。它能将以往零碎、散乱的学科知识整合起来，更能聚焦核心任务、引导建构学科知识框架。 如物质与相互作用”、“能量及其转化等                                                                                                      |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 关键概念   | 关键概念是学科大概念的下位概念，连接学科大概念与具体知识的桥梁性概念，它是学生理解和建构学科大概念所必须掌握的核心性、节点性概念。关键概念具有一定的抽象性（并非具体事实，而是对具体知识的概括）、普遍性（能够广泛迁移到新的情境中）和非时间性（其内涵具有持久性和稳定性，不因具体事件或时间而改变）。关键概念作为连接学科大概念与具体知识内容的桥梁，能够组织和统领一个特定主题或单元内的知识群，将零散的具体知识整合起来，服务于对学科大概念的深层理解和应用，是形成学科思想和原理的工具。 它通常由一个或几个词汇或短语构成（如数学中的“平行”、“内错角”） |
| 知识内容   | 具体知识内容是构成学科知识体系的基础性元素，是学生通过直接学习即可掌握的事实、现象、数据、技能、公式、事件和具体案例等。它具有基础性（是概念建构的起点）、事实性（通常表现为确凿的、可观察和可验证的信息）和散在性（在未经过概念整合前，知识点之间可能显得相对孤立）。具体知识内容是学生形成基本概念、进而抽提关键概念、最终达成对学科大概念理解的素材和基石。教科书中所呈现的多数学生通过学习即可掌握的基础知识。                                                                                                                                              |
