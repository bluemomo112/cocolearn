# 教师端数据可视化改进方案

> **目标**：从"统计性信息"转向"能力画像"，提供全班、个体、跨课程的多维度可视化视图

---

## 一、现状分析

### 1.1 当前问题

**教师主页** (`/teacher/page.tsx`)
- ❌ 只有基础统计（课程数、学生数、待办任务）
- ❌ 缺少班级整体能力概览
- ❌ 缺少学生个体画像的快速入口
- ❌ "教学洞察"Tab只有课程级别数据，没有学生级别数据

**笔记结果页面** (`/teacher/note-config/results-view.tsx`)
- ✅ 已有能力雷达图、能力详情卡片、跨课程时间线
- ⚠️ 但缺少班级整体能力分布
- ⚠️ 缺少学生对比视图
- ⚠️ 缺少能力变化趋势图

### 1.2 参考设计亮点

从 `course/1/analysis` 和 `course/list` 页面学习到：

| 特性 | 价值 | 可借鉴点 |
|------|------|---------|
| **认知起点 vs 学习表现对比** | 体现增值 | 对比前测/后测，展现进步幅度 |
| **分层教学效果分析** | 关注个体差异 | 进步/稳定/需关注三类分组 |
| **知识点掌握条形图** | 直观易懂 | 水平条形图显示百分比 |
| **学生列表双维度显示** | 信息密度高 | 同时显示起点和表现 |
| **进步箭头标注** | 强调成长 | ↑+3分 / ↓-10分 |

## 十、关键技术决策

### 10.1 状态管理

**推荐**: 使用 React Query (TanStack Query) 管理服务器状态

```typescript
// hooks/useTeacherDashboard.ts
export function useTeacherDashboard(teacherId: string) {
  return useQuery({
    queryKey: ['teacherDashboard', teacherId],
    queryFn: () => fetchDashboardData(teacherId),
    staleTime: 5 * 60 * 1000,  // 5分钟缓存
    refetchOnWindowFocus: false,
  });
}
```

**理由**:
- 自动缓存和重新验证
- 减少样板代码
- 与 Next.js App Router 集成良好

### 10.2 图表库选择

**推荐**: recharts + visx 混合使用

```typescript
// recharts 用于常规图表
import { BarChart, LineChart, RadarChart } from 'recharts';

// visx 用于复杂自定义图表
import { XYChart, LineSeries } from '@visx/xychart';
```

**理由**:
- recharts 开发效率高，适合常规图表
- visx 灵活性强，适合复杂定制需求

### 10.3 虚拟化处理

**推荐**: react-virtual 处理长列表

```typescript
import { useVirtualizer } from '@tanstack/react-virtual';

// 用于学生列表、证据列表等可能超过100条的列表
```

**理由**:
- 性能优化，避免渲染大量DOM
- 用户体验流畅
- TanStack生态，与React Query配合良好
