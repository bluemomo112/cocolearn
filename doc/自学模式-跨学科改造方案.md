# 自学模式：跨学科改造方案

> **核心转变**：从「知识点学习 + 复习曲线」转向「能力培养 + 语义化评估 + 跨课程画像」

---

## 一、现状问题诊断

### 1.1 当前设计的问题

| 问题                         | 现状                                                        | 影响               |
| ---------------------------- | ----------------------------------------------------------- | ------------------ |
| **缺乏跨学科特色**     | 当前设计更像通用学习工具，没有体现"能力/思维培养"的核心价值 | 产品无差异化       |
| **知识点设置无意义**   | 教师端没有设置知识点的入口，但学生端又有"概念掌握度雷达图"  | 数据断层，功能虚设 |
| **复习曲线价值有限**   | K12场景下学生是被安排时间学习，不是自主复习                 | 功能闲置           |
| **AI导师缺乏引导策略** | 没有定义AI如何根据上下文、学生能力画像来引导学生            | AI交互无差异化     |
| **评估体系缺失**       | 没有定义如何评估学生的能力表现                              | 无法闭环           |

### 1.2 要砍掉/弱化的功能

- ❌ **复习曲线/复习队列**：K12场景价值有限
- ❌ **知识点诊断**：跨学科更关注能力而非知识点
- ⚠️ **概念掌握度雷达图**：改为「能力维度雷达图」

---

## 二、整体改造方向

### 2.1 新的核心理念

```
┌─────────────────────────────────────────────────────────────────┐
│                      跨学科学习的三大支柱                         │
├─────────────────────────────────────────────────────────────────┤
│  1. 能力维度体系：教师选择本课程关注的能力（批判性思维、信息整合等） │
│  2. AI导师引导策略：基于能力目标 + 学生画像，动态调整引导方式       │
│  3. 语义化评估：课程结束时生成描述性能力报告，累积到跨课程画像      │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 改造范围总览

| 端               | 改造模块      | 改造内容                             |
| ---------------- | ------------- | ------------------------------------ |
| **教师端** | 左侧-任务区   | 移除知识点，增加「能力维度选择」     |
| **教师端** | 中间-交互策略 | 增加「AI引导策略配置」               |
| **教师端** | 右侧-监控区   | 移除复习曲线，改为「能力评估预览」   |
| **学生端** | 中间-AI对话区 | AI根据能力目标+画像进行引导          |
| **学生端** | 右侧-数据Tab  | 移除复习队列，改为「能力成长可视化」 |
| **后端**   | 新增          | Learner Profile（跨课程能力画像）    |
| **后端**   | 新增          | 课程结束时的能力评估Pipeline         |

### 4.2 中间栏：AI对话学习区（核心改造）

#### 4.2.1 AI行为变化

**核心变化**：AI不再是单纯的问答机器，而是「能力培养导师」

| 场景     | 原来的AI   | 改造后的AI                                         |
| -------- | ---------- | -------------------------------------------------- |
| 学生提问 | 直接回答   | 回答后追问「你为什么这样想？」「你能找到证据吗？」 |
| 学生困惑 | 给出解释   | 引导学生自己发现「你觉得可能是什么原因？」         |
| 学生阅读 | 被动等待   | 主动提问「这个观点和之前的资料A有什么联系？」      |
| 阶段结束 | 无特殊行为 | 引导反思「你这个阶段学到了什么？」                 |

### 5.2 关键数据结构

#### 5.2.1 课程配置（教师端产出）

```typescript
interface CourseConfig {
  courseId: string;

  // 能力维度配置（新增）
  competencyConfig: {
    focusedCompetencies: CompetencyType[];  // 本课程关注的能力
    guidanceIntensity: 'low' | 'medium' | 'high';  // AI引导强度
  };

  // 阶段能力目标（新增，可选）
  phaseCompetencyGoals?: {
    [phaseId: string]: CompetencyType[];  // 每个阶段的能力培养目标
  };

  // 其他配置（保留原有）
  resources: Resource[];
  tasks: Task[];
  workflow: WorkflowConfig;
  noteTemplate: string;
}
```

#### 5.2.2 学生画像（跨课程累积）

```typescript
interface LearnerProfile {
  studentId: string;

  // 全局能力画像
  globalCompetencies: {
    [key in CompetencyType]?: {
      overallRating: number;  // 1-4，综合评级
      history: CompetencyHistoryItem[];  // 历史记录
      trend: 'ascending' | 'stable' | 'descending';
      confidence: number;  // 0-1，置信度
      latestObservation: string;  // 最新观察
    };
  };

  // 学习风格（可选，未来扩展）
  learningStyle?: {
    preferredModality: 'visual' | 'textual' | 'interactive';
    questioningPattern: 'proactive' | 'reactive' | 'minimal';
  };

  // 元数据
  metadata: {
    totalCoursesCompleted: number;
    totalLearningTime: number;
    lastActiveAt: Date;
  };
}

interface CompetencyHistoryItem {
  courseId: string;
  courseName: string;
  timestamp: Date;
  rating: number;
  evidence: string[];  // 关键证据
}
```

```markdown
### 2. 能力引导示例

**批判性思维引导**：
- "你为什么这样想？有什么证据支持吗？"

- "这个结论是怎么推导出来的？"

- "不同资料对这个问题的看法一致吗？"

- "你觉得自己理解了多少？哪里还有疑惑？"
- "你用了什么方法来学习这个内容？"
- "如果重新学，你会怎么做？"

**提问质量引导**：
- "这是一个很好的问题！你能把它问得更深入吗？"
- "除了'是什么'，你有没有想过'为什么'？"

**创造性引导**：
- "你能想到其他的可能性吗？"
- "如果换一种方式，会怎么样？"

```

```
## 八、关键决策点（待讨论）

### 8.1 能力维度选择

**建议MVP只做3个核心维度**：
1. 批判性思维
2. 信息整合
3. 元认知

**原因**：这3个维度有明确的行为特征，LLM评估准确度较高。

### 8.2 AI引导强度默认值

**建议默认「中」**：
- 低：可能让AI显得太被动
- 高：可能让学生感到被追问太多

### 8.3 评估触发时机

**建议课程结束时触发**：
- 实时评估成本高、准确度低
- 课程结束有完整数据，评估更准确

### 8.4 跨课程画像的展示

**建议MVP只展示，不用于迁移学习**：
- 先积累数据，验证评估准确性
- 后续再做Manager的迁移学习
```
