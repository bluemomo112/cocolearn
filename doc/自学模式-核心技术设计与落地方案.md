## 1. 核心设计理念

### 1.1 产品定位的再思考

**问题：学生究竟应该如何学习？**

在K12场景下，学生的自学过程不是"自由探索"，而是"有支架的自主学习"（Scaffolded Self-Learning）。系统的核心价值是：

1. **替代低效的自主阅读**：传统自学 = 学生独自啃课件，遇到困难无人问。我们提供AI实时答疑。
2. **替代标准化的课堂讲授**：传统课堂 = 教师按固定节奏教，无法照顾个体差异。我们根据学生状态动态调整。
3. **生成可量化的学习证据**：传统学习过程是黑箱。我们记录完整的学习轨迹，供教师诊断。

**核心设计理念**：
- **学生端**：不是"聊天机器人"，而是"智能学习伙伴" + "隐形导师"。
- **教师端**：不是"配置后台"，而是"教学策略编排工具"。
- **系统**：不是"工具集合"，而是"持续运行的学习教练"。

### 1.2 技术实现的三大支柱

```
┌─────────────────────────────────────────────────────────────┐
│                    系统架构三层模型                           │
├─────────────────────────────────────────────────────────────┤
│  Layer 1: Student Model（学情模型）                          │
│  - 持续跟踪学生的理解状态、困惑点、学习风格                   │
│  - 所有Agent共享，持续更新                                    │
├─────────────────────────────────────────────────────────────┤
│  Layer 2: Manager Engine（调度引擎）                         │
│  - 基于Student Model做决策：下一步该做什么？该用哪个Agent？   │
│  - 实现教学法（BOPPPS/5E）的动态执行                          │
├─────────────────────────────────────────────────────────────┤
│  Layer 3: Agent Ecosystem（智能体生态）                      │
│  - 各司其职的专用Agent：答疑、诊断、批改、元认知...            │
│  - 通过Context获取Student Model，执行后更新Model             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 学情模型（Student Model）设计

### 2.1 为什么需要Student Model？

**问题场景**：
- 学生问："这个我不懂"，AI如何知道"这个"指什么？（需要上下文）
- Manager如何判断学生是否准备好进入下一阶段？（需要状态评估）
- 教师如何看到全班学情？（需要结构化数据）

**解决方案**：维护一个**持续更新的学生状态模型**，作为所有AI决策的数据基础。

### 2.2 Student Model 数据结构

```typescript
interface StudentModel {
  // ============ 基础信息 ============
  studentId: string;
  noteId: string;  // 关联的Note实例
  classNoteId: string;  // 关联的教师配置

  // ============ 学习状态 ============
  currentPhase: {
    phaseName: string;  // 例如："导入阶段"、"概念理解阶段"
    startTime: timestamp;
    currentAgentType: string;  // 当前激活的Agent类型
  };

  // ============ 教学目标达成度 ============
  objectiveProgress: {
    [objectiveId: string]: {
      objectiveName: string;  // 例如："理解光合作用的过程"
      assessmentHistory: [
        {
          timestamp: timestamp;
          method: "task" | "conversation" | "implicit";  // 评估方式
          score: number;  // 0-100
          evidence: string;  // 评估依据
        }
      ];
      currentMastery: number;  // 当前掌握度（加权平均）
      confidence: number;  // 评估置信度（避免误判）
    }
  };

  // ============ 认知状态追踪 ============
  cognitiveState: {
    currentFocus: string;  // 当前关注的资源或概念
    confusionPoints: [
      {
        concept: string;
        detectedAt: timestamp;
        severity: number;  // 困惑程度 1-5
        context: string;  // 学生的原始问题
      }
    ];
    engagementLevel: number;  // 专注度 0-100
    lastActiveTime: timestamp;
  };

  // ============ 学习行为数据 ============
  behaviorLog: {
    totalTimeSpent: number;  // 总学习时长（秒）
    resourceInteractions: [
      {
        resourceId: string;
        action: "open" | "scroll" | "highlight" | "close";
        timestamp: timestamp;
        duration?: number;  // 持续时间
      }
    ];
    conversationStats: {
      totalMessages: number;
      avgResponseTime: number;  // 学生思考时间
      questionTypes: {
        "what": number,  // 事实性问题
        "why": number,   // 解释性问题
        "how": number    // 应用性问题
      }
    };
    taskCompletions: [
      {
        taskId: string;
        completedAt: timestamp;
        score?: number;
        attempts: number;
      }
    ];
  };

  // ============ 学习风格画像 ============
  learningProfile: {
    preferredModality: "visual" | "textual" | "interactive";  // 通过行为推断
    pacingStyle: "fast" | "moderate" | "careful";
    questioningPattern: "proactive" | "reactive" | "minimal";
    difficultyTolerance: number;  // 挫折容忍度
  };

  // ============ 元认知状态 ============
  metacognition: {
    selfAwarenessLevel: number;  // 自我认知水平（通过对话分析）
    strategyUsage: ["summarizing", "self-questioning", ...];  // 使用的学习策略
    lastReflection: {
      content: string;
      timestamp: timestamp;
    };
  };
}
```

### 2.3 Student Model 的更新机制

**核心原则**：每次交互都是数据采集机会。

#### 更新触发点

| 触发事件 | 更新内容 | 实现方式 |
|---------|---------|---------|
| **学生发送消息** | `cognitiveState.currentFocus`<br>`conversationStats` | 通过NLP分析问题类型<br>记录时间戳 |
| **AI回复后** | `objectiveProgress` (隐式评估) | Agent在回复中附带评估标签 |
| **完成任务** | `taskCompletions`<br>`objectiveProgress` (显式评估) | 根据任务绑定的教学目标更新 |
| **打开资源** | `resourceInteractions`<br>`currentFocus` | 前端埋点上报 |
| **长时间无操作** | `engagementLevel` 下降 | 定时器检测 |
| **Manager切换阶段** | `currentPhase` | Manager主动更新 |

#### 更新实现伪代码

```python
class StudentModelUpdater:
    def on_student_message(self, student_id, message, context):
        """学生发送消息时触发"""
        model = self.get_model(student_id)

        # 1. 分析问题类型
        question_type = self.classify_question(message)  # "what"/"why"/"how"
        model.behaviorLog.conversationStats.questionTypes[question_type] += 1

        # 2. 检测困惑信号
        confusion_score = self.detect_confusion(message, context)
        if confusion_score > 0.6:
            model.cognitiveState.confusionPoints.append({
                "concept": self.extract_concept(message),
                "detectedAt": now(),
                "severity": confusion_score * 5,
                "context": message
            })

        # 3. 更新当前关注点
        model.cognitiveState.currentFocus = self.extract_focus(message, context)

        self.save_model(model)

    def on_agent_response(self, student_id, agent_type, response, assessment_tag):
        """Agent回复后触发（隐式评估）"""
        model = self.get_model(student_id)

        # Agent在生成回复时，附带一个内部评估标签
        # 例如：assessment_tag = {"objective_id": "obj_001", "estimated_mastery": 0.7}
        if assessment_tag:
            objective_id = assessment_tag["objective_id"]
            model.objectiveProgress[objective_id].assessmentHistory.append({
                "timestamp": now(),
                "method": "conversation",
                "score": assessment_tag["estimated_mastery"] * 100,
                "evidence": f"基于对话分析：{response[:100]}..."
            })
            # 重新计算当前掌握度（时间衰减 + 加权平均）
            model.objectiveProgress[objective_id].currentMastery = \
                self.calculate_mastery(objective_id, model)

        self.save_model(model)

    def on_task_completion(self, student_id, task_id, result):
        """任务完成时触发（显式评估）"""
        model = self.get_model(student_id)
        task = self.get_task(task_id)

        # 记录任务完成
        model.behaviorLog.taskCompletions.append({
            "taskId": task_id,
            "completedAt": now(),
            "score": result.score,
            "attempts": result.attempts
        })

        # 更新关联的教学目标
        for objective_id in task.linked_objectives:
            model.objectiveProgress[objective_id].assessmentHistory.append({
                "timestamp": now(),
                "method": "task",
                "score": result.score,
                "evidence": f"任务【{task.name}】得分：{result.score}分"
            })

        self.save_model(model)
```

### 2.4 如何避免误判？

**问题**：AI评估学生理解程度，可能出现误判。

**解决方案**：引入**置信度机制**和**多维度验证**。

```python
def calculate_mastery(self, objective_id, model):
    """计算教学目标掌握度（带置信度）"""
    history = model.objectiveProgress[objective_id].assessmentHistory

    # 加权策略：
    # - 任务得分（显式）权重 = 0.7
    # - 对话评估（隐式）权重 = 0.3
    # - 时间衰减：越近的评估权重越高

    weighted_scores = []
    total_weight = 0

    for assessment in history:
        # 时间衰减因子（7天内的评估权重高）
        days_ago = (now() - assessment.timestamp) / (24 * 3600)
        time_weight = exp(-days_ago / 7)  # 指数衰减

        # 方法权重
        method_weight = 0.7 if assessment.method == "task" else 0.3

        # 综合权重
        weight = time_weight * method_weight
        weighted_scores.append(assessment.score * weight)
        total_weight += weight

    # 加权平均
    mastery = sum(weighted_scores) / total_weight if total_weight > 0 else 0

    # 计算置信度（评估次数越多，置信度越高）
    confidence = min(len(history) / 5, 1.0)  # 5次评估达到100%置信
    model.objectiveProgress[objective_id].confidence = confidence

    return mastery
```

**关键设计**：
- **不依赖单次评估**：综合多次数据。
- **任务得分 > 对话推测**：显式评估更可信。
- **时间衰减**：学习是动态的，旧数据权重降低。
- **置信度标记**：告诉Manager"这个判断有多可靠"。

### 3.2 如何测评目标达成？

#### 方法1：显式评估（任务绑定）

**实现**：教师创建任务时，勾选关联的教学目标。

```typescript
interface Task {
  id: string;
  type: "quiz" | "essay" | "agent_interaction";
```

**示例**：
```

- 题目1（单选）：光合作用的场所是？ -> 关联目标：obj_001

  obj_001.currentMastery = 90 (基于题目1的正确性)
  obj_002.currentMastery = 80 (基于题目2的得分)
```

#### 方法2：隐式评估（对话分析）

**挑战**：学生在对话中问了很多问题，如何判断他是否理解了某个目标？

**解决方案**：Agent在回复时，附带内部评估。

```python
class TutorAgent:
    def generate_response(self, student_message, student_model):
        """生成回复 + 隐式评估"""

        # 1. 正常生成回复
        response = self.llm.chat(
            system_prompt=self.get_system_prompt(),
            user_message=student_message,
            context=self.build_context(student_model)
        )

        # 2. 内部评估：判断学生的理解程度
        assessment = self.llm.chat(
            system_prompt="""
            你是一个教学评估专家。根据学生的问题，判断：
            1. 学生当前在问哪个教学目标相关的内容？
            2. 学生的理解程度如何？（0-1分）

            输出JSON格式：
            {
              "objective_id": "obj_001",
              "estimated_mastery": 0.6,
              "reasoning": "学生问了X，说明理解了Y，但还不理解Z"
            }
            """,
            user_message=f"学生问：{student_message}\n我回答了：{response}",
            output_format="json"
        )

        # 3. 返回回复 + 评估标签
        return {
            "response": response,
            "assessment_tag": assessment  # 这个标签不展示给学生，用于更新Student Model
        }
```

**关键点**：
- **双重LLM调用**：一次生成回复，一次做评估（成本增加，但必要）。
- **评估不展示给学生**：学生只看到回复，评估数据进入Student Model。
- **低置信度处理**：对话评估的置信度低于任务，仅作为辅助参考。

#### 方法3：行为推断（补充维度）

**策略**：通过学生的行为模式推断理解程度。

```python
def infer_mastery_from_behavior(student_model, objective_id):
    """基于行为推断掌握度"""
    objective = student_model.objectiveProgress[objective_id]

    # 启发式规则：
    # - 如果学生反复查看相关资源，但不问问题 -> 可能理解了
    # - 如果学生快速略过资源，然后问基础问题 -> 可能没认真学
    # - 如果学生问的问题从"what"变成"why"再变成"how" -> 理解在深化

    related_resources = get_related_resources(objective_id)
    interactions = [i for i in student_model.behaviorLog.resourceInteractions
                    if i.resourceId in related_resources]

    # 计算资源交互深度
    interaction_depth = sum(i.duration for i in interactions) / len(interactions)

    # 计算问题复杂度变化趋势
    question_progression = analyze_question_complexity_trend(student_model, objective_id)

    # 综合推断（权重低，仅作为参考）
    inferred_score = (interaction_depth * 0.4 + question_progression * 0.6) * 100

    return {
        "score": inferred_score,
        "confidence": 0.3  # 行为推断的置信度最低
    }
```

## 4. Manager智能调度引擎

### 4.1 Manager的角色定位

**问题**：Manager不是一个普通的Agent，它是什么？

**回答**：Manager是**元级别的决策系统**，负责：
1. 判断学生当前处于学习流程的哪个阶段
2. 决定下一步该做什么（调用哪个Agent，推送什么任务）
3. 监控学习进度，触发干预

**比喻**：如果各个Agent是"老师"，Manager就是"班主任" + "教学督导"。

### 4.2 Manager的决策依据

Manager的所有决策基于 **Student Model** + **Workflow配置**。

```python
class ManagerEngine:
    def __init__(self, workflow_config, student_model):
        self.workflow = workflow_config  # 教师配置的教学流
        self.student = student_model     # 学生状态
        self.current_phase_index = 0     # 当前阶段索引

    def decide_next_action(self):
        """核心决策函数"""
        current_phase = self.workflow.phases[self.current_phase_index]

        # 1. 检查当前阶段是否完成
        if self.is_phase_completed(current_phase):
            # 进入下一阶段
            self.current_phase_index += 1
            next_phase = self.workflow.phases[self.current_phase_index]
            return self.initialize_phase(next_phase)

        # 2. 当前阶段未完成，判断需要什么行动
        else:
            return self.get_phase_action(current_phase)

    def is_phase_completed(self, phase):
        """判断阶段是否完成（核心逻辑）"""
        completion_criteria = phase.completion_criteria

        # 根据不同的完成条件类型判断
        if completion_criteria.type == "task_based":
            # 基于任务：检查指定任务是否完成
            required_tasks = completion_criteria.required_tasks
            completed_tasks = [t.taskId for t in self.student.behaviorLog.taskCompletions]
            return all(task_id in completed_tasks for task_id in required_tasks)

        elif completion_criteria.type == "objective_based":
            # 基于教学目标：检查目标掌握度是否达标
            required_objectives = completion_criteria.required_objectives
            for obj_id in required_objectives:
                mastery = self.student.objectiveProgress[obj_id].currentMastery
                confidence = self.student.objectiveProgress[obj_id].confidence
                threshold = completion_criteria.mastery_threshold  # 例如：80分

                # 只有在高置信度下才认可掌握度
                if confidence < 0.6 or mastery < threshold:
                    return False
            return True

        elif completion_criteria.type == "conversation_based":
            # 基于对话判断：调用LLM做复杂判断
            recent_conversation = self.get_recent_conversation(limit=10)
            assessment_result = self.llm_assess_understanding(
                conversation=recent_conversation,
                phase_goal=phase.goal
            )
            return assessment_result.is_understood

        elif completion_criteria.type == "time_based":
            # 基于时间：在阶段内至少停留X分钟
            time_in_phase = now() - self.student.currentPhase.startTime
            return time_in_phase >= completion_criteria.min_duration

        else:
            raise ValueError(f"Unknown criteria type: {completion_criteria.type}")
```

**教师端配置**：选择"BOPPPS模型"，系统加载以下Workflow：

### 4.4 Manager的智能判断实现

**场景**：在"参与阶段"，如何判断学生是否理解了"obj_001"？

#### 方案1：阈值判断（简单但可能误判）

```python
def is_objective_mastered_simple(student_model, obj_id, threshold=70):
    """简单版：直接看掌握度分数"""
    mastery = student_model.objectiveProgress[obj_id].currentMastery
    return mastery >= threshold
```

**问题**：
- 如果学生刚进入阶段，还没有评估数据，`currentMastery = 0`，会误判。
- 如果学生蒙对了题，分数虚高，会误判。

#### 方案2：置信度门控（推荐）

```python
def is_objective_mastered_confident(student_model, obj_id, threshold=70):
    """改进版：考虑置信度"""
    progress = student_model.objectiveProgress[obj_id]
    mastery = progress.currentMastery
    confidence = progress.confidence

    # 只有在高置信度下，才认可掌握度
    if confidence < 0.6:  # 置信度不足
        return False

    return mastery >= threshold
```

#### 方案3：LLM判断（复杂但准确）

```python
def is_objective_mastered_llm(student_model, obj_id):
    """最智能版：调用LLM综合判断"""
    objective = get_objective(obj_id)
    recent_conversation = get_recent_conversation(student_model, limit=10)
    recent_resources = get_recent_resources(student_model)

    prompt = f"""
    你是一位经验丰富的教师。请判断学生是否已经掌握以下教学目标：

    教学目标：{objective.name}
    描述：{objective.description}

    证据1 - 最近对话：
    {recent_conversation}

    证据2 - 当前掌握度分数：{student_model.objectiveProgress[obj_id].currentMastery}分
    证据3 - 评估置信度：{student_model.objectiveProgress[obj_id].confidence}

    证据4 - 学习行为：
    - 阅读了资源：{recent_resources}
    - 提问类型分布：{student_model.behaviorLog.conversationStats.questionTypes}

    请综合判断：
    1. 学生是否真正理解了这个目标？（是/否）
    2. 判断依据是什么？
    3. 如果还没掌握，差在哪里？

    输出JSON：
    {{
      "is_mastered": true/false,
      "reasoning": "...",
      "gap": "..."
    }}
    """

    result = llm.chat(prompt, output_format="json")
    return result["is_mastered"]
```

**成本分析**：
- **方案1**：无额外成本，但误判率高。
- **方案2**：无额外成本，误判率中等（推荐作为默认方案）。
- **方案3**：每次判断调用1次LLM（~500 tokens），成本高，但最准确（可作为"严格模式"选项）。

**建议策略**：
- 默认使用方案2（置信度门控）。
- 教师可在配置中开启"智能判断模式"，使用方案3（增加成本，但提升质量）。

### 4.5 Manager的干预机制

**问题**：如果学生卡在某个阶段太久怎么办？

**解决方案**：Manager主动干预。

```python
class ManagerEngine:
    def monitor_and_intervene(self):
        """监控 + 干预"""
        current_phase = self.workflow.phases[self.current_phase_index]
        time_in_phase = now() - self.student.currentPhase.startTime

        # 干预规则1：超时干预
        if time_in_phase > current_phase.max_duration:
            return self.intervene_timeout(current_phase)

        # 干预规则2：困惑累积干预
        active_confusions = [c for c in self.student.cognitiveState.confusionPoints
                             if c.severity >= 3]
        if len(active_confusions) >= 3:
            return self.intervene_confusion(active_confusions)

        # 干预规则3：参与度低干预
        if self.student.cognitiveState.engagementLevel < 30:
            return self.intervene_disengagement()

        return None  # 无需干预

    def intervene_timeout(self, phase):
        """超时干预：降低难度或跳过"""
        return {
            "action": "push_message",
            "content": "我注意到这部分内容比较难，要不要我换个方式解释？",
            "options": [
                {"label": "换个方式解释", "action": "switch_agent", "agent": "简化版Agent"},
                {"label": "先跳过这部分", "action": "skip_phase"},
                {"label": "我再看看", "action": "continue"}
            ]
        }

    def intervene_confusion(self, confusions):
        """困惑干预：主动提供帮助"""
        return {
            "action": "push_message",
            "content": f"看起来你对【{confusions[0].concept}】有些疑惑，我来帮你梳理一下...",
            "follow_up": "call_agent",
            "agent_type": "答疑Agent",
            "context": {"focus_concept": confusions[0].concept}
        }
```

## 5. Context与Memory管理

### 5.1 三层记忆模型

**问题**：AI如何"记住"学生之前说过什么？

**解决方案**：分层管理不同时效的信息。

```
┌─────────────────────────────────────────────────────┐
│  Layer 1: 短期上下文 (Short-term Context)           │
│  - 当前对话的最近10轮                                │
│  - 当前打开的资源                                    │
│  - 存储位置：内存（前端state + 后端session）          │
│  - 生命周期：本次对话session                         │
└─────────────────────────────────────────────────────┘
            ↓ 重要信息提取
┌─────────────────────────────────────────────────────┐
│  Layer 2: 工作记忆 (Working Memory)                 │
│  - 本次学习session的关键事件                         │
│  - 例如：学生问过的核心问题、完成的任务               │
│  - 存储位置：数据库（session级别）                    │
│  - 生命周期：本次学习session（例如：今天下午的学习）  │
└─────────────────────────────────────────────────────┘
            ↓ 持久化重要状态
┌─────────────────────────────────────────────────────┐
│  Layer 3: 长期记忆 (Long-term Memory)               │
│  - Student Model（完整的学习档案）                   │
│  - 存储位置：数据库（永久）                           │
│  - 生命周期：整个课程周期                            │
└─────────────────────────────────────────────────────┘
```

### 5.2 Agent如何使用Context？

**每个Agent在生成回复前，都会构建Context**：

```python
class BaseAgent:
    def build_context(self, student_model, conversation_history):
        """构建Agent的上下文"""
        context = {
            # ===== 从Student Model提取 =====
            "student_profile": {
                "current_focus": student_model.cognitiveState.currentFocus,
                "confusion_points": student_model.cognitiveState.confusionPoints[-3:],  # 最近3个困惑
                "learning_style": student_model.learningProfile.preferredModality
            },

            "objective_progress": {
                obj_id: {
                    "name": obj.objectiveName,
                    "mastery": obj.currentMastery,
                    "confidence": obj.confidence
                }
                for obj_id, obj in student_model.objectiveProgress.items()
            },

            # ===== 从对话历史提取 =====
            "recent_conversation": conversation_history[-10:],  # 最近10轮

            # ===== 从资源库提取 =====
            "current_resource": self.get_current_resource(student_model),

            # ===== 从Workflow提取 =====
            "current_phase": student_model.currentPhase.phaseName,
            "phase_goal": self.get_phase_goal(student_model.currentPhase.phaseName)
        }

        return context

    def generate_response(self, student_message, student_model, conversation_history):
        """生成回复"""
        context = self.build_context(student_model, conversation_history)

        system_prompt = f"""
        你是一个{self.agent_type}。

        当前学生状态：
        - 正在学习：{context['current_resource']['title']}
        - 当前阶段：{context['current_phase']}（目标：{context['phase_goal']}）
        - 关注焦点：{context['student_profile']['current_focus']}
        - 困惑点：{', '.join([c.concept for c in context['student_profile']['confusion_points']])}

        教学目标进度：
        {json.dumps(context['objective_progress'], indent=2)}

        请根据以上上下文，回答学生的问题。
        """

        response = self.llm.chat(
            system_prompt=system_prompt,
            messages=context['recent_conversation'] + [student_message]
        )

        return response
```

### 5.3 Memory的持久化策略

**问题**：对话历史会越来越长，不能全部塞给LLM（token限制）。

**解决方案**：滑动窗口 + 摘要压缩。

```python
class MemoryManager:
    def get_conversation_for_llm(self, student_id, max_tokens=4000):
        """获取适合LLM的对话历史"""
        full_history = self.db.get_conversation_history(student_id)

        # 策略1：最近N轮直接保留
        recent_messages = full_history[-10:]
        recent_tokens = count_tokens(recent_messages)

        if recent_tokens < max_tokens:
            # token充足，直接返回
            return recent_messages
        else:
            # token不足，压缩历史
            # 保留最近5轮 + 历史摘要
            recent_5 = full_history[-5:]
            older_messages = full_history[:-5]

            # 调用LLM生成摘要
            summary = self.llm.chat(f"""
            请将以下对话压缩成简短摘要（300字以内），保留关键信息：
            {older_messages}
            """)

            return [
                {"role": "system", "content": f"历史对话摘要：{summary}"}
            ] + recent_5
```

```python
def generate_teacher_dashboard(class_note_id):
    """生成教师看板"""
    # 1. 获取所有学生的Student Model
    student_notes = db.query(StudentNote).filter(classNoteId=class_note_id).all()

    # 2. 聚合统计
    dashboard = {
        "overview": {
            "totalStudents": len(student_notes),
            "activeStudents": sum(1 for s in student_notes
                                  if s.lastActiveAt > now() - 24*3600),
            "avgProgress": mean([calculate_progress(s) for s in student_notes]),
            "avgTimeSpent": mean([s.studentModel.behaviorLog.totalTimeSpent
                                  for s in student_notes]) / 60
        }
    }

    # 3. 教学目标达成分布
    objectives = get_objectives(class_note_id)
    objective_distribution = {}

    for obj_id in objectives:
        masteries = [s.studentModel.objectiveProgress[obj_id].currentMastery
                     for s in student_notes]

        objective_distribution[obj_id] = {
            "objectiveName": objectives[obj_id].name,
            "masteryDistribution": {
                "0-60": sum(1 for m in masteries if m < 60),
                "60-80": sum(1 for m in masteries if 60 <= m < 80),
                "80-100": sum(1 for m in masteries if m >= 80)
            },
            "avgMastery": mean(masteries),
            "lowPerformers": [s.studentId for s in student_notes
                              if s.studentModel.objectiveProgress[obj_id].currentMastery < 60]
        }

    dashboard["objectiveDistribution"] = objective_distribution

    # 4. 困难点热力图
    all_confusions = []
    for s in student_notes:
        all_confusions.extend(s.studentModel.cognitiveState.confusionPoints)

    confusion_counts = {}
    for c in all_confusions:
        if c.concept not in confusion_counts:
            confusion_counts[c.concept] = {"count": 0, "total_severity": 0}
        confusion_counts[c.concept]["count"] += 1
        confusion_counts[c.concept]["total_severity"] += c.severity

    dashboard["confusionHeatmap"] = [
        {
            "concept": concept,
            "studentCount": data["count"],
            "avgSeverity": data["total_severity"] / data["count"]
        }
        for concept, data in confusion_counts.items()
    ]

    # 按困惑学生数排序
    dashboard["confusionHeatmap"].sort(key=lambda x: x["studentCount"], reverse=True)

    return dashboard
```

### 7.1 完整学习流程示例

**场景**：学生开始学习一个配置了BOPPPS流程的课程。

```python

    workflow=student_note.inheritedConfig.workflow,

        # 更新Student Model
        StudentModelUpdater.on_task_completion(
            student_id, task.id, result
        )

    elif action.type == "enable_free_chat":
        # 进入自由对话阶段
        agent = AgentFactory.create(
            agent_type=action.agent_type,
            config=student_note.inheritedConfig.agentConfig
        )

        # 对话循环
        while not manager.is_phase_completed(manager.current_phase):
            # 等待学生输入
            user_message = await frontend.wait_for_user_input()

            # Agent生成回复
            response_data = agent.generate_response(
                student_message=user_message,
                student_model=student_model,
                conversation_history=get_conversation_history(student_id)
            )

            # 展示回复
            frontend.display_message(response_data["response"])

            # 更新Student Model（隐式评估）
            StudentModelUpdater.on_agent_response(
                student_id,
                agent.agent_type,
                response_data["response"],
                response_data["assessment_tag"]
            )

            # Manager检查是否需要干预
            intervention = manager.monitor_and_intervene()
            if intervention:
                frontend.display_message(intervention["content"])

    # 2. 检查阶段完成条件
    if manager.is_phase_completed(manager.current_phase):
        # 进入下一阶段
        manager.advance_to_next_phase()
        student_model.currentPhase = manager.get_current_phase_info()

# ===== 学习完成 =====
final_report = generate_learning_report(student_model)
frontend.display_completion_screen(final_report)
```

### 7.2 AI批改任务的实现

```python
class AIGrader:
    def grade_task(self, task, student_submission, teacher_rubric):
        """AI批改任务"""

        if task.type == "quiz":
            # 客观题：直接判断
            return self.grade_quiz(student_submission, task.correct_answers)

        elif task.type == "essay":
            # 主观题：LLM批改
            return self.grade_essay(student_submission, teacher_rubric)

        elif task.type == "agent_interaction":
            # 与Agent互动的任务：分析对话记录
            return self.grade_interaction(student_submission, task.criteria)

    def grade_essay(self, essay_text, rubric):
        """批改主观题"""
        prompt = f"""
        你是一位专业教师。请根据以下评分标准，批改学生的回答。

        评分标准：
        {rubric.criteria}

        学生回答：
        {essay_text}

        请输出：
        1. 得分（0-100）
        2. 评语（简短，指出优点和不足）
        3. 改进建议

        输出JSON格式：
        {{
          "score": 85,
          "comment": "...",
          "suggestions": "..."
        }}
        """

        result = llm.chat(prompt, output_format="json")

        return {
            "score": result["score"],
            "feedback": {
                "comment": result["comment"],
                "suggestions": result["suggestions"]
            }
        }

    def grade_interaction(self, conversation_log, criteria):
        """批改Agent互动任务

        例如：任务要求学生"说服辩论Agent"，通过条件是"AI判定说服力>80分"
        """
        prompt = f"""
        你是一位辩论教练。请评估学生在以下对话中的表现。

        任务要求：{criteria.description}
        通过标准：{criteria.passing_condition}

        对话记录：
        {conversation_log}

        请评估：
        1. 学生是否达到了任务要求？
        2. 说服力得分（0-100）
        3. 表现评价

        输出JSON：
        {{
          "passed": true/false,
          "score": 85,
          "evaluation": "..."
        }}
        """

        result = llm.chat(prompt, output_format="json")
        return result
```

### 7.3 元认知监控的实现

```python
class MetacognitionMonitor:
    def __init__(self, monitoring_rules):
        self.rules = monitoring_rules

    def check_and_trigger(self, student_model):
        """检查并触发干预"""
        triggered_interventions = []

        for rule in self.rules:
            if self.is_rule_triggered(rule, student_model):
                intervention = self.generate_intervention(rule, student_model)
                triggered_interventions.append(intervention)

        return triggered_interventions

    def is_rule_triggered(self, rule, student_model):
        """判断规则是否触发"""
        if rule.type == "idle_too_long":
            idle_time = now() - student_model.cognitiveState.lastActiveTime
            return idle_time > rule.threshold  # 例如：10分钟

        elif rule.type == "confusion_accumulated":
            active_confusions = [c for c in student_model.cognitiveState.confusionPoints
                                 if c.severity >= 3]
            return len(active_confusions) >= rule.threshold  # 例如：3个

        elif rule.type == "low_engagement":
            return student_model.cognitiveState.engagementLevel < rule.threshold  # 例如：<30

        elif rule.type == "stuck_in_phase":
            time_in_phase = now() - student_model.currentPhase.startTime
            return time_in_phase > rule.max_duration  # 例如：30分钟

    def generate_intervention(self, rule, student_model):
        """生成干预内容"""
        if rule.intervention_type == "gentle_reminder":
            return {
                "type": "notification",
                "message": "还在吗？需要帮助吗？😊",
                "priority": "low"
            }

        elif rule.intervention_type == "offer_help":
            return {
                "type": "agent_message",
                "message": "我注意到你可能遇到了困难，让我帮你梳理一下...",
                "agent": "答疑Agent",
                "priority": "medium"
            }

        elif rule.intervention_type == "alert_teacher":
            return {
                "type": "teacher_alert",
                "message": f"学生{student_model.studentId}在【{student_model.currentPhase.phaseName}】停留过久，可能需要帮助。",
                "priority": "high"
            }
```

## 8. 成本与可行性分析

### 8.1 LLM调用成本估算

**假设**：使用GPT-4o（价格：$2.5/1M input tokens, $10/1M output tokens）

#### 单个学生学习一节课的Token消耗

| 场景 | 调用次数 | Input Tokens | Output Tokens | 小计成本 |
|------|---------|--------------|---------------|---------|
| **对话交互**（学生问20个问题） | 20 | 1000/次 × 20 | 300/次 × 20 | $0.11 |
| **隐式评估**（每次对话后） | 20 | 500/次 × 20 | 200/次 × 20 | $0.065 |
| **Manager判断**（阶段切换6次） | 6 | 800/次 × 6 | 100/次 × 6 | $0.018 |
| **AI批改**（2个主观题） | 2 | 600/次 × 2 | 400/次 × 2 | $0.011 |
| **总计** | 48 | 约33k tokens | 约10k tokens | **$0.2/人/课** |

#### 优化策略

1. **缓存System Prompt**：OpenAI的Prompt Caching可减少50%的重复token成本。
2. **使用更便宜的模型**：
   - 对话Agent：GPT-4o-mini ($0.15/1M) -> 成本降至$0.03/人/课
   - 隐式评估：可用国产模型（如文心4.0，$0.8/1M） -> 成本降至$0.05/人/课
3. **按需调用**：隐式评估不需要每次对话都做，可以每3轮触发1次。

**结论**：**单人单课成本可控制在$0.05以内（¥0.35）**，规模化后可接受。

## 9. 关键问题的答案总结

### 9.1 学生究竟应该如何学习？

**答**：学生的学习路径由Manager调度，具体流程为：

1. **导入阶段**：Manager推送引导消息，激发兴趣。
2. **目标明确**：展示教学目标，让学生知道"要学什么"。
3. **前测诊断**：通过任务了解学生起点。
4. **主动探索**：学生与Agent对话，阅读资源，系统持续更新Student Model。
5. **智能干预**：Manager监控状态，在学生困惑/分心时主动介入。
6. **后测评估**：检验学习效果，更新目标达成度。
7. **反思总结**：引导元认知，巩固知识。

**核心**：学生不是"自由放飞"，而是在**智能脚手架**的支持下自主学习。

### 9.2 系统如何感知上下文？

**答**：通过**三层记忆模型** + **Student Model**：

- **短期上下文**：当前对话的最近10轮 + 当前打开的资源。
- **工作记忆**：本次学习session的关键事件。
- **长期记忆**：Student Model（完整学习档案）。

每个Agent在生成回复前，都会从Student Model中提取相关信息（当前关注点、困惑点、目标进度等）作为上下文。

### 9.3 教师端和学生端数据如何交互？

**答**：

1. **教师端 -> 学生端**：
   - 教师配置生成ClassNote（模板）。
   - 学生Fork后生成StudentNote（实例），继承配置。

2. **学生端 -> 教师端**：
   - 学生学习过程持续更新Student Model。
   - 后端定时聚合所有学生的Model，生成教师看板。

3. **实时同步**：
   - 前端通过WebSocket接收Manager的推送。
   - Student Model的关键字段（如目标进度）前后端同步。

### 9.4 如何避免"看起来很美"但无法落地？

**答**：本文档的所有设计都提供了：

1. **明确的数据结构**（TypeScript接口）。
2. **可执行的伪代码**（Python示例）。
3. **成本估算**（LLM调用费用）。
4. **技术选型**（具体框架）。
5. **实施路线**（MVP -> 增强 -> 规模化）。

**关键原则**：
- 不依赖"黑魔法"，所有判断逻辑都可解释。
- 引入置信度机制，避免AI误判。
- 分阶段实施，先验证核心假设再扩展。
