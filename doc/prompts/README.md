# 学习平台Agent提示词系统

## 概述

本文档系统包含了一套完整的AI Agent提示词,用于构建智能化的学习平台。这些Agent基于NotebookLM的理念,帮助学生基于上传的学习资料进行自主学习,提供个性化的学习支持、引导和监控。

## 系统架构

提示词系统分为四大类:

```
提示词系统
├── 任务型Agent (Task Agents)       - 执行特定学习任务
├── 对话型Agent (Chat Agents)       - 提供互动式学习支持
├── 工作流 (Workflows)               - 组合多个Agent的完整学习流程
└── 监控型Agent (Monitoring Agents) - 监控学习过程并提供反馈
```

---

## 一、任务型Agent (Task Agents)

任务型Agent执行明确的学习任务,输出结构化结果。主要用于学习任务区,学生点击后Agent执行任务并返回结果。

### 1.1 题目生成Agent
- **文件:** `task-agents/题目生成Agent.md`
- **功能:** 基于学习资料生成测试题目
- **输出:** JSON格式的题目(包括选择题、判断题、简答题等)
- **适用场景:** 课后练习、自我测试、知识巩固

### 1.2 单选题生成Agent
- **文件:** `task-agents/单选题生成Agent.md`
- **功能:** 专门生成高质量单选题
- **输出:** JSON格式的单选题(含干扰选项和详细解析)
- **适用场景:** 概念理解测试、快速检验

### 1.3 案例分析题生成Agent
- **文件:** `task-agents/案例分析题生成Agent.md`
- **功能:** 生成真实情境的案例分析题
- **输出:** JSON格式的案例题(含情境、问题和评分标准)
- **适用场景:** 应用能力培养、综合分析训练

### 1.4 批改Agent
- **文件:** `task-agents/批改Agent.md`
- **功能:** 快速批改学生作答,给出得分和简短反馈
- **输出:** JSON格式的批改结果(得分、对错、简要反馈)
- **适用场景:** 即时反馈、大量练习批改

### 1.5 详细反馈批改Agent
- **文件:** `task-agents/详细反馈批改Agent.md`
- **功能:** 深度批改,提供详细的逐题分析和改进建议
- **输出:** JSON格式的详细反馈(逐题分析、优缺点、知识关联)
- **适用场景:** 重要测试、需要深入理解的作业

### 1.6 资料概览Agent
- **文件:** `task-agents/资料概览Agent.md`
- **功能:** 生成学习资料的概览,帮助学生快速了解内容结构
- **输出:** JSON格式的概览(大纲、关键概念、学习路径)
- **适用场景:** 学习开始前、预习、复习

### 1.7 难点解释Agent
- **文件:** `task-agents/难点解释Agent.md`
- **功能:** 识别并解释学习资料中的难点
- **输出:** JSON格式的难点解释(难点列表、通俗解释、类比、示例)
- **适用场景:** 突破学习瓶颈、理解复杂概念

## 二、对话型Agent (Chat Agents)

对话型Agent通过对话方式与学生互动,提供不同风格的学习引导。学生在学习过程中可以随时呼出这些Agent提问。

### 2.1 标准助教
- **文件:** `chat-agents/标准助教.md`
- **风格:** 直接、清晰、结构化
- **特点:** 快速给出答案,附带解释和资料定位
- **适用场景:** 快速解答、概念查询、标准讲解
- **典型回答结构:** 直接答案 → 详细解释 → 示例 → 资料位置

### 2.2 苏格拉底式
- **文件:** `chat-agents/苏格拉底式.md`
- **风格:** 提问引导、不给直接答案
- **特点:** 通过层层提问,引导学生自己找到答案
- **适用场景:** 培养批判性思维、深度理解、概念辨析
- **核心方法:** 反问→追问→层层深入→自我发现

### 2.3 循循善诱型
- **文件:** `chat-agents/循循善诱型.md`
- **风格:** 温和引导、渐进式提示
- **特点:** 介于直接回答和苏格拉底式之间,给予分层提示
- **适用场景:** 学生需要引导但又不希望完全靠自己、中等难度问题
- **提示层级:** 方向提示→关键点提示→接近答案的提示

### 2.4 费曼式
- **文件:** `chat-agents/费曼式.md`
- **风格:** 学生教Agent、暴露知识盲区
- **特点:** Agent扮演外行,学生解释概念,发现理解不足之处
- **适用场景:** 检验理解深度、巩固知识、准备教学/分享
- **典型对话:** "你能教我XX吗?"→学生解释→"这个词什么意思?"→暴露盲区

### 2.5 辩论对手
- **文件:** `chat-agents/辩论对手.md`
- **风格:** 挑战观点、反驳论证
- **特点:** 对学生的观点提出挑战,培养论证能力
- **适用场景:** 培养批判性思维、论证能力、观点深化
- **挑战方式:** 逻辑挑战、证据挑战、反例挑战、替代方案挑战

### 2.6 质疑者
- **文件:** `chat-agents/质疑者.md`
- **风格:** 不断追问"为什么"
- **特点:** 不满足于表面回答,追问到底层原理
- **适用场景:** 深入理解原理、区分"知道"和"理解"
- **核心方法:** 5个为什么、追问证据、追问推导过程

## 三、工作流 (Workflows)

工作流是多个Agent和学习步骤的组合,形成完整的学习方法论。每个工作流基于经典的教学/学习理论。

### 3.1 费曼学习法
- **文件:** `workflows/费曼学习法.md`
- **理论基础:** 以教促学,通过教别人来深化理解
- **流程:** 选择概念→学习→解释(教学)→发现盲区→重新学习→简化和类比→巩固→总结
- **总时长:** 60-90分钟
- **核心Agent:** 费曼式对话Agent
- **适用场景:** 深度理解概念、准备教学、知识内化

### 3.2 SQ3R阅读学习法
- **文件:** `workflows/SQ3R阅读学习法.md`
- **理论基础:** 主动阅读,从被动接受到主动建构
- **流程:** Survey(浏览)→Question(提问)→Read(阅读)→Recite(复述)→Review(复习)
- **总时长:** 80-130分钟
- **核心Agent:** 资料概览Agent、标准助教、费曼式对话Agent
- **适用场景:** 大量阅读材料、教材学习、论文阅读

### 3.3 问题导向学习(PBL)
- **文件:** `workflows/问题导向学习PBL.md`
- **理论基础:** 从问题出发,在解决问题中学习
- **流程:** 问题呈现→问题分析→自主学习→知识整合→方案制定→评估→反思
- **总时长:** 90-130分钟
- **核心Agent:** 案例分析题生成Agent(改编)、苏格拉底式、质疑者、辩论对手
- **适用场景:** 应用性强的内容、培养问题解决能力、跨章节综合学习

### 3.4 BOPPPS模型
- **文件:** `workflows/BOPPPS模型.md`
- **理论基础:** 完整学习闭环,目标导向
- **流程:** Bridge-in(导入)→Objective(目标)→Pre-assessment(前测)→Participatory Learning(参与式学习)→Post-assessment(后测)→Summary(总结)
- **总时长:** 75-110分钟
- **核心Agent:** 标准助教、题目生成Agent、批改Agent、详细反馈批改Agent
- **适用场景:** 系统学习一个完整模块、明确学习目标、需要看到进步

### 3.5 5E探究法
- **文件:** `workflows/5E探究法.md`
- **理论基础:** 建构主义,主动探索和发现
- **流程:** Engage(引入)→Explore(探索)→Explain(解释)→Elaborate(迁移)→Evaluate(评价)
- **总时长:** 75-100分钟
- **核心Agent:** 标准助教、苏格拉底式、费曼式、题目生成Agent
- **适用场景:** 学习新概念、培养探究能力、有探索性的内容

## 四、监控型Agent (Monitoring Agents)

监控型Agent在学习过程中持续监控学生行为,给予适时反馈和鼓励,帮助学生保持良好的学习状态。

### 4.1 温柔陪伴型
- **文件:** `monitoring-agents/温柔陪伴型.md`
- **风格:** 温柔、鼓励、陪伴
- **特点:** 关注情绪,及时鼓励,营造温暖氛围
- **适用场景:** 需要情感支持、容易焦虑、自信心不足的学生
- **监控维度:** 学习时长、进度、状态、情绪
- **反馈方式:** 温柔提醒、正面鼓励、理解支持

### 4.2 严格督导型
- **文件:** `monitoring-agents/严格督导型.md`
- **风格:** 严格、明确、纪律性
- **特点:** 设定标准,及时指正,督促执行
- **适用场景:** 自制力弱、需要外部约束、需要养成习惯的学生
- **监控维度:** 计划执行、任务完成、学习纪律
- **反馈方式:** 明确要求、及时警告、奖惩分明

### 4.3 教练型
- **文件:** `monitoring-agents/教练型.md`
- **风格:** 目标导向、激励、策略指导
- **特点:** 追踪目标进度,分析表现,提供突破策略
- **适用场景:** 有明确目标、追求进步、准备考试的学生
- **监控维度:** 目标进度、能力提升、强弱项、挑战完成
- **反馈方式:** 数据分析、进步追踪、挑战设定、策略建议

### 4.4 静默记录型
- **文件:** `monitoring-agents/静默记录型.md`
- **风格:** 静默、客观、数据化
- **特点:** 不打扰学习过程,仅记录数据,定期生成报告
- **适用场景:** 自主性强、不喜欢被打扰、仅需数据记录的学生
- **监控维度:** 学习时间、内容覆盖、任务完成、行为模式
- **反馈方式:** 学习结束后报告、周报、月报、按需查询

## 系统特性

### 知识边界控制

所有Agent的系统提示词中都包含 `{KNOWLEDGE_BOUNDARY_SETTING}` 占位符,教师可以配置Agent对学习资料的依赖程度:

- **严格模式:** Agent只能基于上传的学习资料回答,不能引入外部知识
- **平衡模式:** (推荐)以学习资料为主,必要时可补充常识性解释
- **开放模式:** 可以引入外部知识,但需标注来源

这通过RAG(检索增强生成)技术实现,确保AI不会"瞎编"超出资料范围的内容。

### 个性化配置

每个Agent和工作流都提供教师可配置项,包括:

- **难度级别:** 简单/中等/困难
- **引导强度:** 高度引导/中度引导/低度引导
- **反馈详细度:** 简洁/标准/详尽
- **特殊指令:** 教师可添加针对特定学生的附加指令

### 结构化输出

任务型Agent采用JSON格式输出,便于系统解析和展示:

```json
{
  "questions": [...],
  "score": 85,
  "feedback": {...},
  ...
}
```

### 多Agent协作

工作流通过组合不同Agent实现复杂学习过程:

- 任务Agent生成学习材料(题目、概览等)
- 对话Agent提供互动支持
- 监控Agent追踪学习状态

## 使用场景

### 场景1:自主学习新章节

1. 学生上传教材PDF
2. 使用"资料概览Agent"快速了解结构
3. 选择"BOPPPS工作流"进行系统学习
4. 学习过程中遇到难点,呼出"循循善诱型"Agent提问
5. "温柔陪伴型"监控Agent全程陪伴鼓励
6. 学习结束后查看"静默记录型"生成的学习报告

### 场景2:备考复习

1. 学生上传复习资料
2. 设定目标(如"期末考试80分以上")
3. "教练型"监控Agent帮助追踪目标进度
4. 使用"题目生成Agent"自动生成练习题
5. 使用"详细反馈批改Agent"批改,分析薄弱点
6. 针对薄弱点,使用"难点解释Agent"深入理解
7. 教练Agent根据进度调整学习计划

### 场景3:深度理解难点概念

1. 学生标记难以理解的概念
2. 选择"费曼学习法工作流"
3. 尝试向"费曼式"Agent解释概念
4. Agent扮演外行,提出"不懂"的问题,暴露盲区
5. 学生重新学习,再次尝试解释
6. 使用类比和示例,真正内化理解

### 场景4:培养批判性思维

1. 学生阅读观点性文章/案例
2. 呼出"辩论对手"Agent
3. 表达自己的观点
4. Agent从各个角度挑战观点
5. 学生论证、修正、深化观点
6. 培养严密的逻辑思维能力

## 技术实现建议

### Agent调用流程

```
用户请求
   ↓
识别意图(任务/对话/监控)
   ↓
选择对应Agent
   ↓
注入系统提示词 + 知识边界设定 + 学习资料(RAG)
   ↓
调用LLM生成响应
   ↓
解析输出(如果是JSON)
   ↓
返回给用户
```

### 工作流编排

工作流通过状态机实现:

```
工作流定义(步骤、Agent、跳转条件)
   ↓
当前步骤执行
   ↓
用户交互
   ↓
判断跳转条件
   ↓
下一步骤 或 结束
```

### RAG集成

```
用户上传资料
   ↓
文档切片(Chunking)
   ↓
向量化(Embedding)
   ↓
存储到向量数据库
   ↓
用户提问时,检索相关片段
   ↓
注入到Agent提示词
   ↓
Agent基于资料回答
```
