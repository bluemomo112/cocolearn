# SQ3R阅读学习法

## 工作流名称
SQ3R高效阅读学习工作流

## 介绍
SQ3R是一种经典的阅读学习方法,包含Survey(浏览)、Question(提问)、Read(阅读)、Recite(复述)、Review(复习)五个步骤,帮助学生更高效地阅读和理解学习资料。

## 适用场景
- 面对大量阅读材料时
- 需要深度理解和长期记忆阅读内容
- 适合文字为主的学习资料(教材、论文、报告等)

## 学习目标
- 提高阅读效率和理解深度
- 将被动阅读转变为主动学习
- 增强记忆和复习效果

## 工作流步骤

### 步骤1:浏览(Survey)
**目标:**快速浏览资料,了解整体结构和主要内容

**Agent配置:**
- **Agent类型:**资料概览Agent
- **指令:**
  ```
  为学生生成「{学习资料/章节}」的概览:

  **包含以下内容:**
  1. **结构大纲:**章节标题、主要部分
  2. **核心主题:**这份资料主要讲什么
  3. **关键概念:**列出重要的术语和概念(不展开解释)
  4. **预计阅读时间:**根据资料篇幅估算
  5. **阅读建议:**哪些部分是重点,哪些可以略读

  **浏览指导:**
  "在开始详细阅读之前,先快速浏览一遍资料:
  - 看看标题和小标题,了解结构
  - 注意加粗、斜体的关键词
  - 看看图表和插图
  - 如果有章节小结,先读一下

  这个过程不需要仔细读每个字,重点是建立整体印象。"
  ```

**输出:**
- 资料概览报告(大纲、主题、关键概念)
- 阅读策略建议

**预计时间:**5-10分钟

---

### 步骤2:提问(Question)
**目标:**将标题和主题转化为问题,带着问题阅读

**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  帮助学生基于「{学习资料}」的结构,生成阅读问题:

  **方法1:将标题转化为问题**
  - 标题:"光合作用的过程" → 问题:"光合作用的过程是怎样的?包含哪些阶段?"
  - 标题:"光合作用的影响因素" → 问题:"哪些因素会影响光合作用?如何影响?"

  **方法2:基于学习目标提问**
  - "这一章节要让我理解什么?"
  - "学完后我应该能回答哪些问题?"

  **生成5-8个问题,涵盖本次阅读的核心内容。**

  **引导学生:**
  "现在,你也可以基于概览,提出1-2个你自己感兴趣的问题。"

  最终整合为一个"阅读问题清单"。
  ```

**输出:**
- 阅读问题清单(包含系统生成的和学生自己提出的)

**预计时间:**5-8分钟

---

### 步骤3:阅读(Read)
**目标:**带着问题,主动寻找答案地阅读

**分为两个子环节:**

#### 3.1 主动阅读
**提示:**
```
现在,开始详细阅读资料。

**阅读策略:**
带着你的问题清单阅读:
{显示问题清单}

**阅读时:**
- 当发现某个段落回答了你的某个问题时,标注出来
- 遇到重要概念、定义、公式,标注重点
- 遇到不理解的地方,标注疑问
- 尝试在脑海中组织信息,而非被动接受

**阅读提示:**
- 不要逐字逐句死读,重点是理解意思
- 主动思考:"这段在说什么?和我的问题有什么关系?"
- 如果某段特别难懂,可以先跳过,继续往下读,可能后面会有解释

**阅读过程中,可随时呼出助教提问。**

阅读完成后,点击"下一步"。
```

**可配置对话Agent:**学生在阅读过程中可以随时提问

**预计时间:**20-40分钟(取决于资料篇幅)

#### 3.2 检查问题清单
**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  引导学生检查阅读问题清单:

  "阅读完成后,让我们回顾一下问题清单。对于每个问题,你能回答吗?"

  逐个问题询问学生:
  - "问题1:[问题内容],你能回答吗?"
  - 如果学生能回答,让其简要说一下答案
  - 如果学生答不上来,提示:"这个问题在资料的第X部分有讲到,你可以重点回顾一下。"

  **记录:**
  - 已能回答的问题(说明阅读有效)
  - 还不能回答的问题(需要重点复习)
  ```

**输出:**
- 问题回答情况(已掌握/未掌握)
- 需要重点复习的部分

**预计时间:**8-10分钟

---

### 步骤4:复述(Recite)
**目标:**合上资料,用自己的话复述核心内容

**Agent配置:**
- **Agent类型:**费曼式对话Agent
- **指令:**
  ```
  现在,请学生合上资料(不看资料),用自己的话复述「{学习主题}」的核心内容。

  **复述要求:**
  "请用3-5分钟,不看资料,用自己的话说说这次阅读的主要内容:
  - 核心观点是什么?
  - 主要讲了哪几个方面?
  - 关键概念有哪些?你能解释吗?"

  **你扮演聆听者:**
  - 当学生复述时,适时提问:"你刚才提到[XX],能详细说说吗?"
  - 当学生卡壳时,提示:"你还记得关于[XX]的部分吗?"
  - 当学生用专业术语时,要求:"能用更简单的话解释吗?"

  **复述结束后:**
  - 指出学生复述得好的地方:"你清楚地说明了[XX],说明你理解了。"
  - 指出遗漏的重要内容:"资料中还有一个重点是[XX],你没有提到。"
  - 建议:"你可能需要重点复习[XX]部分。"

  **记录学生的复述和遗漏点。**
  ```

**输出:**
- 学生的复述内容
- 遗漏的重要知识点
- 需要加强的部分

**预计时间:**10-15分钟

---

### 步骤5:复习(Review)
**目标:**系统复习,巩固记忆,填补盲区

**分为三个子环节:**

#### 5.1 针对性复习
**提示:**
```
根据刚才的复述,你需要重点复习以下内容:

**需要加强的知识点:**
{列出复述中遗漏的或不清楚的部分}

**建议:**
- 重新阅读资料的相关部分
- 特别留意刚才没注意到的细节
- 尝试理解为什么自己会遗漏这些内容

重新阅读这些部分后,点击"下一步"。
```

**预计时间:**10-15分钟

#### 5.2 知识整理
**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  引导学生整理知识:

  "为了巩固学习成果,请你选择一种方式整理今天阅读的内容:

  **选项1:思维导图**
  用文字描述一个思维导图结构:
  - 中心主题是什么?
  - 有几个主要分支?
  - 每个分支下有哪些要点?

  **选项2:大纲笔记**
  按照层级结构整理:
  - 一级标题(主要主题)
  - 二级标题(子主题)
  - 要点和细节

  **选项3:问答笔记**
  把阅读内容整理成问答对:
  - 问题1:XXX → 答案:XXX
  - 问题2:XXX → 答案:XXX

  学生选择一种方式后,给予整理指导。整理完成后,检查其完整性并给予反馈。
  ```

**输出:**学生整理的学习笔记

**预计时间:**10-15分钟

#### 5.3 复习测试
**Agent配置:**
- **Agent类型:**快速批改Agent
- **指令:**
  ```
  生成3-5道测试题,检验学生的阅读理解:

  **题型:**
  - 2-3道选择/判断题:考查关键概念
  - 1-2道简答题:考查理解和应用

  **题目来源:**
  基于步骤2的"阅读问题清单"和步骤4中学生的"遗漏点"。

  **批改后:**
  - 给出得分和反馈
  - 如果得分不理想,建议再次复习相关部分
  - 如果得分良好,肯定学生的阅读学习成果
  ```

**输出:**
- 测试得分
- 复习建议(如需要)

**预计时间:**10-15分钟

---

### 步骤6:学习总结
**目标:**总结SQ3R学习法的效果和体会

**提示:**
```
恭喜你完成了「{学习资料}」的SQ3R阅读学习!

**回顾你的学习过程:**
- **浏览阶段:**用{时间}建立了整体印象
- **提问阶段:**提出了{问题数}个阅读问题
- **阅读阶段:**主动寻找答案,标注了重点和疑问
- **复述阶段:**不看资料,复述了核心内容,发现了{遗漏点数}个盲区
- **复习阶段:**针对性复习,整理笔记,测试得分{分数}

**请思考并回答:**
1. SQ3R方法和你平时的阅读方式有什么不同?
2. 你觉得哪个步骤对你帮助最大?为什么?
3. "带着问题阅读"和"直接从头读到尾"相比,有什么优势?
4. 这次阅读,你记住了哪些核心内容?

**你的学习笔记已保存,建议:**
- 24小时后,快速复习一次笔记(艾宾浩斯遗忘曲线)
- 1周后,再次测试,巩固长期记忆

**下次阅读学习,可以继续使用SQ3R方法!**
```

**输出:**学习总结和反思

**预计时间:**5分钟

---

## 工作流总结

**总预计时间:**80-130分钟(取决于资料篇幅)

**学习成果:**
- 深度理解和记忆阅读内容
- 形成结构化的学习笔记
- 掌握主动阅读的方法
- 建立高效的阅读学习习惯

**适合学生类型:**
- 面对大量阅读材料,需要提高效率
- 希望将阅读转化为真正的理解和记忆
- 愿意投入时间进行系统化阅读

**SQ3R的优势:**
- **主动而非被动:**带着问题寻找答案,而非被动接受
- **结构化阅读:**从宏观到微观,层层深入
- **及时检验:**通过复述和测试,发现盲区
- **记忆牢固:**多次接触和主动加工,增强记忆

## 教师可配置项

**浏览深度:**
- 快速浏览(仅看标题和大纲)
- 中等浏览(推荐,包含关键概念)
- 深度浏览(包含每段摘要)

**问题生成:**
- 由系统全部生成
- 系统生成 + 学生补充(推荐)
- 主要由学生自己提问

**复述要求:**
- 简要复述(3分钟,抓主要内容)
- 详细复述(5-8分钟,包含细节,推荐)
- 完整复述(10分钟以上,尽可能全面)

**笔记模板:**
- 教师可提供推荐的笔记模板(思维导图/大纲/康奈尔笔记等)
- 或让学生自由选择
