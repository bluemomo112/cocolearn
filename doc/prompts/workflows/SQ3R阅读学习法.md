# SQ3R阅读学习法

## 工作流名称
SQ3R高效阅读学习工作流

## 介绍
SQ3R是一种经典的阅读学习方法,包含Survey(浏览)、Question(提问)、Read(阅读)、Recite(复述)、Review(复习)五个步骤,帮助学生更高效地阅读和理解学习资料。AI引导者会全程陪伴学生,主动推送学习资源、引导带着问题阅读、检验理解成果,将被动阅读转变为主动学习。

## 适用场景
- 面对大量阅读材料时
- 需要深度理解和长期记忆阅读内容
- 适合文字为主的学习资料(教材、论文、报告等)

## 学习目标
- 提高阅读效率和理解深度
- 将被动阅读转变为主动学习
- 增强记忆和复习效果

SQ3R阅读学习法工作流需要以下输入参数:

```json
    "estimated_duration": 90,
    "knowledge_prerequisites": [
      "前置知识点1",
      "前置知识点2"
    ]
  },
  "resources": [
    {
      "id": "resource_1",
      "type": "document|pdf|article|textbook",
      "title": "资源标题",
      "url": "资源地址",
      "description": "资源描述",

          "section_title": "章节标题",
          "page_range": "1-5",
          "importance": "high|medium|low"
        }
      ],
      "tags": ["核心概念", "原理解释", "应用示例"]
    }
  ],
  "tasks": [
    {
      "id": "task_1",
      "title": "任务标题",
      "type": "test|assignment|practice",
      "description": "任务描述",
      "test_type": "choice|short_answer|essay",
      "questions": [...],
      "due_date": "截止日期",
      "priority": "high|medium|low"
    }
  ],
  "workflow_config": {
    "guidance_level": "high|medium|low",
    "survey_depth": "quick|moderate|thorough",
    "question_generation_mode": "system|mixed|student",
    "recite_requirement": "brief|moderate|detailed",
    "enable_note_template": true,
    "enable_post_test": true
  }
}
```

**参数说明:**
- `reading_topic`: 本次阅读的主题,用于聚焦学习目标
- `resources`: 阅读资源列表,需标注content_type(核心/补充/例子/练习)和key_sections(重点章节)
- `workflow_config.survey_depth`: 浏览深度(quick仅看标题大纲,moderate包含关键概念,thorough包含每段摘要)
- `workflow_config.question_generation_mode`: 问题生成模式(system全部由系统生成,mixed系统生成+学生补充,student主要由学生提问)
- `workflow_config.recite_requirement`: 复述要求(brief简要3分钟,moderate详细5-8分钟,detailed全面10分钟以上)
- `workflow_config.enable_note_template`: 是否提供笔记模板

```
- 不是知识的灌输者,而是阅读方法的引导者

- 引导学生整理笔记,巩固记忆

- `file_search`: 在学习资料中搜索相关内容,生成概览、定位重点章节

- **及时肯定:** 当学生能回答问题、复述清晰时,给予肯定
```

```
**阅读策略:**

**1. 主动寻找答案**
- 阅读时,脑海中想着这些问题
- 当发现某个段落回答了某个问题,标注出来
- 在问题旁边简要记录答案要点

**2. 标注重点**
- 重要概念、定义、公式 → 标注⭐
- 例子和应用 → 标注📌
- 不理解的地方 → 标注❓

- 重点是理解意思,而非记住每个字

- 核心概念部分 → 慢读,仔细理解
- 例子和说明部分 → 适中
- 已知内容 → 可以快速浏览
```

**目标:** 合上资料,用自己的话复述核心内容,发现理解盲区

```
- 发现理解盲区,知道哪些地方还需要加强
- 将知识内化为自己的语言,而非照搬书本

---

**请你合上资料(不看资料),用自己的话说说这次阅读的主要内容。**

{根据recite_requirement调整复述要求}

{如果recite_requirement=brief}

- 用3分钟左右
- 说说核心观点和主要内容
- 不要求覆盖所有细节

{如果recite_requirement=moderate}

- 用5-8分钟
```

## 工作流总结

**总预计时间:** 85-135分钟(取决于资料篇幅)

**学习成果:**
- 深度理解和记忆阅读内容
- 形成结构化的学习笔记
- 掌握主动阅读的方法
- 建立高效的阅读学习习惯

**适合学生类型:**
- 面对大量阅读材料,需要提高效率
- 希望将阅读转化为真正的理解和记忆
- 愿意投入时间进行系统化阅读

**SQ3R的优势:**
- **主动而非被动:** 带着问题寻找答案,而非被动接受
- **结构化阅读:** 从宏观到微观,层层深入
- **及时检验:** 通过复述和测试,发现盲区
- **记忆牢固:** 多次接触(浏览-阅读-复述-复习)和主动加工,增强记忆

**SQ3R的挑战:**
- 时间投入较多(需完整走完5个步骤)
- 需要一定的自我管理和反思能力
- 初次使用可能觉得"麻烦",但熟练后会大幅提高效率

## 教师可配置项

**浏览深度:**
- `survey_depth`:
  - `quick`: 快速浏览(仅看标题和大纲)
  - `moderate`: 中等浏览(推荐,包含关键概念)
  - `thorough`: 深度浏览(包含每段摘要)

**问题生成模式:**
- `question_generation_mode`:
  - `system`: 由系统全部生成(适合初学者)
  - `mixed`: 系统生成 + 学生补充(推荐,平衡引导和自主)
  - `student`: 主要由学生自己提问(适合高水平学生)

**复述要求:**
- `recite_requirement`:
  - `brief`: 简要复述(3分钟,抓主要内容)
  - `moderate`: 详细复述(5-8分钟,包含细节,推荐)
  - `detailed`: 完整复述(10分钟以上,尽可能全面)

**笔记模板:**
- `enable_note_template`:
  - `true`: 提供推荐的笔记模板(思维导图/大纲/问答/康奈尔笔记等)
  - `false`: 学生自由选择笔记方式

**测试配置:**
- `enable_post_test`: 是否包含复习测试(默认true)
- 优先使用tasks中预设的测试,没有则自动生成

## 与其他工作流的区别

**vs. 费曼学习法:**
- 费曼侧重"深度理解单个概念",SQ3R侧重"高效阅读大量资料"
- 费曼通过"教别人"检验理解,SQ3R通过"复述"检验理解

**vs. 5E探究法:**
- 5E侧重"探索发现",SQ3R侧重"系统阅读"
- 5E适合科学实验类,SQ3R适合文字资料类

**vs. PBL问题导向学习:**
- PBL从问题出发综合应用知识,SQ3R从阅读资料出发系统学习
- PBL培养问题解决能力,SQ3R培养阅读理解能力

**SQ3R的独特价值:**
通过5个系统化步骤(Survey-Question-Read-Recite-Review),将"被动阅读"转变为"主动学习",大幅提高阅读效率和记忆效果。特别适合需要阅读大量文字资料的学习场景。
