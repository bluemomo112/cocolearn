# 费曼学习法

## 工作流名称
费曼学习法工作流

## 介绍
基于诺贝尔奖得主理查德·费曼的学习方法,通过"以教促学"的方式,让学生用最简单的语言解释概念,从而检验和深化理解。这个工作流引导学生完成完整的费曼学习循环。

## 适用场景
- 学习抽象概念,需要真正理解而非死记硬背
- 检验自己是否真正掌握了知识
- 将复杂概念内化为自己的理解

## 学习目标
- 将知识内化,能够用自己的话解释
- 发现理解盲区并针对性补强
- 培养深度理解能力

## 工作流步骤

### 步骤1:选择概念
**目标:**确定要深入学习的概念

**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  帮助学生从学习资料中选择一个核心概念进行深入学习。

  询问学生:
  1. 你想深入理解哪个概念?
  2. 如果不确定,我可以根据资料为你推荐几个重要的核心概念。

  如果学生选择了概念,确认这个概念在资料中确实存在且重要。
  如果学生让你推荐,从资料中选择3-5个核心概念,简要说明每个概念的重要性,让学生选择。
  ```

**输出:**学生选定的概念

**预计时间:**2-3分钟

---

### 步骤2:初步学习
**目标:**学生阅读资料,初步理解概念

**提示:**
```
现在,请你先阅读资料中关于「{选定概念}」的部分。

**学习建议:**
- 仔细阅读相关章节
- 标注重点和不太理解的地方
- 尝试记住关键词和定义

**相关资料位置:**
{自动定位资料中该概念的章节}

阅读完成后,点击"下一步"。
```

**无Agent交互,纯学习阶段**

**预计时间:**10-15分钟(取决于概念复杂度)

---

### 步骤3:用自己的话解释(第一次尝试)
**目标:**学生尝试用简单语言解释概念,暴露理解盲区

**Agent配置:**
- **Agent类型:**费曼式对话Agent
- **指令:**
  ```
  现在,请学生假装在教一个完全不懂这个领域的人,用最简单的语言解释「{选定概念}」。

  你要扮演一个外行人:
  - 听不懂专业术语,要求学生用日常语言解释
  - 对抽象概念感到困惑,要求举例说明
  - 发现学生解释不清楚的地方,指出盲区

  当学生解释有以下问题时,要指出:
  - 使用了过多专业术语而未解释
  - 解释过于抽象,缺少具体例子
  - 逻辑跳跃,中间缺少连接
  - 表述模糊或含混

  在对话结束时,总结学生理解得好的地方和存在盲区的地方。
  ```

**输出:**
- 学生的解释记录
- 识别出的理解盲区列表

**预计时间:**10-15分钟

---

### 步骤4:回顾资料,针对性学习
**目标:**针对盲区,重新学习相关内容

**Agent配置:**
- **Agent类型:**难点解释Agent
- **指令:**
  ```
  根据上一步识别出的盲区:{盲区列表},为学生提供针对性的解释和学习建议。

  对于每个盲区:
  1. 指出资料中对应的章节
  2. 用简化的语言重新解释这个难点
  3. 提供类比和例子
  4. 给出学习建议

  鼓励学生重点复习这些盲区部分。
  ```

**输出:**针对每个盲区的解释和学习指导

**预计时间:**10-15分钟

---

### 步骤5:再次解释(完善版)
**目标:**学生重新解释概念,检验是否填补了盲区

**Agent配置:**
- **Agent类型:**费曼式对话Agent
- **指令:**
  ```
  现在,请学生再次用简单语言解释「{选定概念}」,这次要尝试填补之前的盲区。

  你依然扮演外行人,但这次要特别关注:
  - 学生是否填补了之前的盲区
  - 解释是否比第一次更清晰
  - 是否能用自己的话,而非背诵资料

  当学生解释得好时,明确肯定。
  如果仍有不清楚的地方,温和指出,并建议再次学习。

  最后,评价学生这一轮的解释比第一轮进步了多少。
  ```

**输出:**
- 改进后的解释记录
- 仍存在的盲区(如果有)
- 进步评价

**预计时间:**10-15分钟

---

### 步骤6:简化和类比
**目标:**将概念简化到极致,创造自己的类比

**Agent配置:**
- **Agent类型:**循循善诱型
- **指令:**
  ```
  引导学生将「{选定概念}」简化和类比化:

  1. 让学生用一句话总结这个概念的核心
  2. 引导学生创造一个生活化的类比:"这就像..."
  3. 引导学生举一个具体的例子

  对学生的简化和类比给予反馈:
  - 如果准确且形象,给予肯定
  - 如果有偏差,温和纠正
  - 如果学生想不出类比,给予提示

  最终目标:让学生有一个自己的"记忆锚点"。
  ```

**输出:**
- 一句话概括
- 学生创造的类比
- 学生的例子

**预计时间:**5-10分钟

---

### 步骤7:知识巩固
**目标:**通过题目测试,巩固理解

**Agent配置:**
- **Agent类型:**题目生成Agent(简答题为主)
- **指令:**
  ```
  根据「{选定概念}」生成2-3道简答题,考查学生对这个概念的理解。

  题目要求:
  - 不要问"是什么"的定义题,而要问"为什么""怎么样""如果...会怎样"的理解题
  - 难度适中,能检验学生是否真正理解
  - 鼓励学生用自己的话回答,而非背诵
  ```

**学生答题后,自动批改并反馈**

**预计时间:**10-15分钟

---

### 步骤8:学习总结
**目标:**学生总结学习收获和心得

**提示:**
```
恭喜你完成了「{选定概念}」的费曼学习法!

**请用3-5分钟总结一下:**
1. 你对这个概念的理解,和学习之前相比有什么变化?
2. 通过"教别人"的方式学习,你有什么体会?
3. 你创造的类比/例子是什么?以后回忆这个概念时,你会想到这个类比吗?

**学习记录:**
- 概念:{选定概念}
- 初次解释盲区数:{盲区数量}
- 最终掌握程度:{根据测试得分评价}
- 你的类比:"{学生的类比}"

你的学习笔记已自动保存。
```

**输出:**学习总结,自动保存到笔记

**预计时间:**5分钟

---

## 工作流总结

**总预计时间:**60-90分钟

**学习成果:**
- 对一个核心概念的深度理解
- 发现并填补理解盲区
- 创造个性化的记忆方法(类比/例子)
- 通过测试验证掌握程度

**适合学生类型:**
- 希望深度理解概念,而非浅层记忆
- 有一定自主学习能力
- 愿意花时间反复打磨理解

## 教师可配置项

**概念推荐:**
- 自动推荐资料中的核心概念
- 或由教师预设推荐列表

**难度调整:**
- 外行人"程度"(完全外行/有基础知识)
- 测试题难度

**时间控制:**
- 是否允许学生分多次完成工作流
- 每个步骤的建议时间
