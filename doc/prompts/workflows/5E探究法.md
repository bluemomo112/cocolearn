# 5E探究法

## 工作流名称
5E探究式学习工作流

## 介绍
基于建构主义学习理论的5E教学模式(Engage, Explore, Explain, Elaborate, Evaluate),通过"引入-探索-解释-迁移-评价"五个环节,引导学生主动探究和建构知识。

## 适用场景
- 学习新概念或原理时
- 需要培养探究能力和科学思维
- 适合有一定探索性和开放性的学习内容

## 学习目标
- 主动探索和发现知识,而非被动接受
- 建立新旧知识的联系
- 培养科学探究能力和批判性思维

## 工作流步骤

### 步骤1:引入(Engage)
**目标:**激发学生兴趣和好奇心,引出学习主题

**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  通过以下方式引入学习主题「{学习主题}」,激发学生的兴趣:

  1. 提出一个引人入胜的问题或现象
  2. 展示一个有趣的事实或矛盾的现象
  3. 联系学生的生活经验

  **示例引入方式:**
  - "你有没有想过,为什么植物的叶子是绿色的?"
  - "这里有个奇怪的现象:植物在黑暗中会死亡,但在光下却能生长,这是为什么?"
  - "你知道你呼吸的氧气,大部分来自植物吗?它们是怎么制造氧气的?"

  然后询问学生:
  - "关于这个问题/现象,你有什么想法?"
  - "你之前了解过类似的内容吗?"
  - "你觉得可能的答案是什么?"

  记录学生的初始想法(可能是错误的,这很正常)。
  ```

**输出:**
- 引入的问题/现象
- 学生的初始想法和假设

**预计时间:**5-8分钟

---

### 步骤2:探索(Explore)
**目标:**学生自主探索资料,寻找线索和信息

**Agent配置:**
- **Agent类型:**苏格拉底式对话Agent
- **指令:**
  ```
  引导学生探索资料中关于「{学习主题}」的内容,但不要直接告诉答案。

  **引导方式:**
  - "让我们一起来探索资料。你觉得应该从哪个章节开始看?"
  - "你在资料中看到了哪些关键信息?"
  - "这些信息能帮助你回答我们之前的问题吗?"
  - "你注意到[某个现象/数据]了吗?这意味着什么?"

  **当学生发现关键信息时:**
  - "很好!你发现了[关键点]。那么这和我们的问题有什么关系?"
  - "继续这个思路,你还能发现什么?"

  **当学生迷失方向时:**
  - "让我给你一个提示:重点关注资料的第X节。"
  - "想想我们的问题是关于什么的?资料的哪个部分可能相关?"

  在这个阶段,鼓励学生自己发现和提出想法,而非给出标准答案。
  ```

**输出:**
- 学生发现的关键信息
- 学生形成的初步理解

**预计时间:**15-20分钟

---

### 步骤3:解释(Explain)
**目标:**学生用自己的话解释发现,形成对概念的理解

**Agent配置:**
- **Agent类型:**费曼式对话Agent
- **指令:**
  ```
  现在,让学生用自己的话解释他们的发现和理解。

  **引导学生解释:**
  - "基于你在资料中的发现,你能解释一下「{学习主题}」是什么/为什么/怎么样吗?"
  - "请用最简单的语言,像教外行人一样,说说你的理解。"

  **你扮演外行人,提问:**
  - 当学生使用专业术语时:"这个词是什么意思?"
  - 当学生解释抽象时:"能举个例子吗?"
  - 当学生逻辑跳跃时:"从这一步到那一步,是怎么推导的?"

  **当学生解释比较完整时:**
  - 将学生的解释与资料中的标准解释对比
  - 指出学生理解得好的地方和还需要完善的地方
  - 补充学生遗漏的关键点

  **输出学生的解释和资料标准解释的对比。**
  ```

**输出:**
- 学生的解释(用自己的话)
- 与标准解释的对比
- 需要完善的地方

**预计时间:**15-20分钟

---

### 步骤4:迁移(Elaborate)
**目标:**将概念应用到新情境,深化和拓展理解

**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  帮助学生将「{学习主题}」的概念迁移到新的情境或更复杂的情况。

  **提供2-3个迁移任务,例如:**

  1. **应用到新情境:**
     "现在你理解了光合作用的原理,那么请思考:如果把植物放在完全红光或完全蓝光的环境中,光合作用效率会有差异吗?为什么?"

  2. **与其他概念联系:**
     "光合作用和呼吸作用有什么关系?它们是相反的过程吗?"

  3. **解决实际问题:**
     "如果你是一个农民,想提高作物产量,基于光合作用原理,你会采取哪些措施?"

  **引导学生:**
  - 运用刚学到的概念思考这些问题
  - 将概念与相关知识联系起来
  - 发现概念的应用价值

  对学生的回答给予反馈和补充。
  ```

**输出:**
- 迁移任务及学生的回答
- 学生对概念的深化理解

**预计时间:**15-20分钟

---

### 步骤5:评价(Evaluate)
**目标:**通过测试评估学习效果,并让学生自我反思

**分为两部分:**

#### 5.1 知识测试
**Agent配置:**
- **Agent类型:**题目生成Agent + 批改Agent
- **指令:**
  ```
  生成3-4道题目,全面评估学生对「{学习主题}」的理解:

  1. 1道选择题:考查基本概念理解
  2. 1道简答题:考查原理解释
  3. 1道应用题/案例题:考查知识迁移能力
  4. (可选)1道综合题:考查与其他概念的联系

  批改后,给出详细反馈。
  ```

**输出:**测试得分和详细反馈

**预计时间:**15-20分钟

#### 5.2 自我反思
**提示:**
```
请回顾整个学习过程,思考以下问题:

1. **知识层面:**
   - 你对「{学习主题}」的理解,和学习之前相比有什么变化?
   - 还有哪些疑问或不清楚的地方?

2. **方法层面:**
   - 在"探索"阶段,你是怎么找到关键信息的?
   - 在"迁移"阶段,你觉得哪个应用最有挑战性?为什么?

3. **元认知层面:**
   - 这种"自己探索"的学习方式,和直接听讲解相比,你觉得有什么不同?
   - 你更喜欢哪种方式?为什么?

**你的学习足迹:**
- 初始想法:"{步骤1记录的想法}"
- 最终理解:"{步骤3的解释}"
- 测试得分:"{测试分数}"

请写下你的反思(3-5分钟)。
```

**输出:**学生的反思笔记

**预计时间:**10分钟

---

## 工作流总结

**总预计时间:**75-100分钟

**学习成果:**
- 通过自主探索建构的深度理解
- 概念在新情境中的应用能力
- 科学探究思维的训练
- 学习方法的元认知反思

**适合学生类型:**
- 喜欢主动探索,不满足于接受答案
- 有较强的自主学习能力
- 愿意花时间深入思考

**与传统学习的区别:**
- 不是从定义开始,而是从问题/现象开始
- 不是被动接受,而是主动发现
- 不是孤立记忆,而是联系建构

## 教师可配置项

**引入方式:**
- 教师可自定义引入的问题或现象
- 或由系统根据资料自动生成

**探索指导度:**
- 高度引导(给较多提示)
- 中度引导(推荐)
- 低度引导(让学生充分自主探索)

**迁移任务:**
- 教师可自定义迁移情境
- 或由系统根据资料生成

**评价标准:**
- 设定测试题难度
- 设定通过分数线
