# BOPPPS模型

## 工作流名称
BOPPPS高效学习工作流

## 介绍
BOPPPS是一种经典的教学设计模型,包含Bridge-in(导入)、Objective(学习目标)、Pre-assessment(前测)、Participatory Learning(参与式学习)、Post-assessment(后测)、Summary(总结)六个环节。这个工作流将BOPPPS应用于自主学习场景,形成完整的学习闭环。

## 适用场景
- 系统学习一个完整的知识模块或章节
- 需要明确学习目标和效果检验
- 适合结构化、目标明确的学习内容

## 学习目标
- 带着明确目标进行学习
- 了解学习前后的进步
- 通过参与式学习提高主动性
- 形成完整的学习闭环

## 工作流步骤

### 步骤1:导入(Bridge-in)
**目标:**激活已有知识,建立新旧知识的联系

**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  帮助学生为学习「{学习章节/主题}」做准备:

  1. **联系已有知识:**
     "在学习[新主题]之前,让我们先回顾一下你已经知道的内容。"
     - "关于[相关主题],你还记得哪些内容?"
     - "之前我们学过[前置知识],你还有印象吗?"

  2. **激活兴趣:**
     提出一个引人思考的问题或展示一个有趣的现象,与本次学习主题相关。
     例如:"你有没有想过,为什么..."

  3. **预告学习内容:**
     "今天我们要学习[主题],它和你之前了解的[相关内容]有密切关系。"

  **记录学生对前置知识的回忆情况。**
  ```

**输出:**
- 前置知识回顾
- 引入问题/现象

**预计时间:**5-8分钟

---

### 步骤2:学习目标(Objective)
**目标:**明确本次学习要达成的目标

**提示:**
```
本次学习的目标是:

**知识目标:**
- 理解[核心概念1]的定义和原理
- 掌握[核心概念2]的特点和应用
- 了解[概念3]与[概念4]之间的关系

**能力目标:**
- 能够用自己的话解释[核心概念]
- 能够运用[原理]解决[类型问题]
- 能够区分[概念A]和[概念B]

**学习完成标准:**
- 完成后测得分达到__分以上(满分10分)
- 能够独立完成[类型任务]
- 能够举例说明[应用场景]

**预计学习时间:**{总时间}分钟

**相关资料:**第{章节}

请仔细阅读学习目标,明确你要达成的效果。准备好后,点击"下一步"。
```

**无Agent交互,学生阅读目标**

**预计时间:**2-3分钟

---

### 步骤3:前测(Pre-assessment)
**目标:**了解学生的起点水平,发现已有认知和盲区

**Agent配置:**
- **Agent类型:**快速批改Agent
- **指令:**
  ```
  生成3-5道测试题,评估学生在学习前对「{学习主题}」的了解程度:

  **题型:**
  - 2-3道选择题:考查基本概念认知
  - 1-2道简答题:了解学生的已有理解

  **题目特点:**
  - 不要太难,学生可能答不全是正常的
  - 覆盖本次学习的核心内容
  - 目的是诊断,而非考试

  **批改后,生成前测报告:**
  - 学生答对的部分(说明学生已经了解)
  - 学生答错或不会的部分(说明学习重点)
  - 建议学习时重点关注的内容

  **鼓励学生:**
  "前测答不好是正常的,这帮助我们了解你的起点,从而更有针对性地学习!"
  ```

**输出:**
- 前测得分
- 前测诊断报告(强项和薄弱点)
- 建议学习重点

**预计时间:**10-15分钟

---

### 步骤4:参与式学习(Participatory Learning)
**目标:**学生主动学习资料,完成学习任务

**分为两个子环节:**

#### 4.1 资料学习
**提示:**
```
现在,开始学习资料内容。

**根据前测结果,你需要重点关注:**
{前测报告中的薄弱点}

**学习建议:**
- 带着刚才的学习目标阅读
- 遇到前测中不会的题目涉及的知识点,要特别留意
- 标注重点和疑问

**资料位置:**第{章节}

学习过程中,如有疑问,可以随时向我提问。

阅读完成后,点击"下一步"进入互动环节。
```

**可配置对话Agent:**在学习过程中,学生可随时呼出对话Agent提问(如标准助教、循循善诱型等)

**预计时间:**20-30分钟

#### 4.2 互动巩固
**Agent配置:**
- **Agent类型:**根据学习内容选择(如费曼式/苏格拉底式)
- **指令:**
  ```
  通过对话帮助学生巩固对「{学习主题}」的理解:

  **互动方式:**
  - 让学生用自己的话解释核心概念
  - 针对前测中的薄弱点,重点提问
  - 引导学生建立概念之间的联系
  - 通过举例和应用加深理解

  **关注前测薄弱点:**
  前测显示学生在[某个知识点]上较弱,要特别引导这部分的理解。

  **对话目标:**
  确保学生对核心内容有清晰的理解,能用自己的话表达,而非仅仅记住定义。
  ```

**输出:**互动对话记录,学生对核心概念的解释

**预计时间:**15-20分钟

---

### 步骤5:后测(Post-assessment)
**目标:**评估学习效果,对比前后进步

**Agent配置:**
- **Agent类型:**详细反馈批改Agent
- **指令:**
  ```
  生成后测题目,评估学生学习后的掌握情况:

  **题目设计:**
  - 覆盖本次学习的核心内容
  - 难度与学习目标匹配
  - 包含部分前测中的题目(以便对比进步)
  - 包含新题目(考查学习目标达成度)

  **题型:**
  - 3-4道选择/判断题:考查基本概念
  - 2-3道简答/应用题:考查理解和应用

  **批改后,生成对比报告:**
  - 后测得分 vs 前测得分
  - 进步最大的知识点
  - 仍需加强的知识点
  - 是否达到学习目标

  对学生的进步给予肯定,对薄弱点给出学习建议。
  ```

**输出:**
- 后测得分
- 前后测对比报告
- 学习目标达成评价
- 改进建议(如果有薄弱点)

**预计时间:**15-20分钟

---

### 步骤6:总结(Summary)
**目标:**回顾整个学习过程,巩固所学,规划后续

**Agent配置:**
- **Agent类型:**标准助教
- **指令:**
  ```
  帮助学生总结本次学习:

  1. **知识总结:**
     "请你用3-5句话,总结一下本次学习的核心内容。"
     如果学生总结不完整,提示遗漏的要点。

  2. **学习成果回顾:**
     展示学生的学习数据:
     - 前测得分:{前测分数}
     - 后测得分:{后测分数}
     - 进步:{进步幅度}
     - 学习目标达成度:{达成/部分达成/未达成}

  3. **查漏补缺:**
     如果后测仍有薄弱点:"你在[知识点]上还需要加强,建议你..."

  4. **后续学习建议:**
     - "巩固今天所学,可以[具体建议]"
     - "为了深化理解,建议阅读资料的扩展部分"
     - "下一次学习,我们将学习[相关主题],与今天的内容有联系"

  最后,鼓励学生并肯定其努力。
  ```

**学生输入自己的总结后,Agent进行反馈和补充**

**输出:**
- 学生的知识总结
- 完整的学习报告(前后测对比、目标达成度等)
- 后续学习建议

**预计时间:**8-10分钟

---

## 工作流总结

**总预计时间:**75-110分钟

**学习成果:**
- 系统掌握一个完整的知识模块
- 清晰看到学习前后的进步(前后测对比)
- 通过主动参与提高学习效果
- 明确下一步的学习方向

**适合学生类型:**
- 喜欢有明确目标和反馈的学习
- 适合系统化、结构化学习
- 希望看到自己进步的学生

**BOPPPS的优势:**
- **目标驱动:**带着明确目标学习,效率更高
- **诊断先行:**前测帮助找到学习重点
- **主动参与:**不是被动接受,而是主动建构
- **效果可见:**后测验证学习成果,增强成就感
- **完整闭环:**从导入到总结,形成完整的学习循环

## 教师可配置项

**学习目标:**
- 教师可自定义学习目标和完成标准
- 或由系统根据资料自动生成

**前测难度:**
- 简单(仅考查基础认知)
- 中等(推荐,全面诊断)
- 困难(包含较难题目)

**后测通过标准:**
- 设定及格分数线(如70分)
- 设定优秀分数线(如85分)

**参与式学习的对话Agent选择:**
- 费曼式(适合深度理解)
- 苏格拉底式(适合批判性思维)
- 循循善诱型(适合需要引导的学生)
