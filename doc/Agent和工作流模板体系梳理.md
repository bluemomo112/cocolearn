# AI智能体与工作流模板体系梳理
> 基于NotebookLM式学习平台的实际场景

## 核心场景定位
这是一个基于**上传资料进行自主学习**的平台，核心是帮助学生：
1. 理解和消化学习资料
2. 通过对话深化理解
3. 做笔记整理知识
4. 通过测验巩固学习

---

## 一、现有PRD中已提及的模板

### 1. 左侧栏 - 任务区
- **题目生成**：根据资料生成单选/多选/主观题
- **AI批改**：自动批改并给出反馈

### 2. 中间栏 - 自由对话
- 标准助教、循循善诱型、苏格拉底式、辩论对手

### 3. 中间栏 - 引导学习工作流
- BOPPPS教学模型、5E探究法、费曼学习法

### 4. 右侧栏 - 监控与笔记
- 监控策略：严格监督型、温柔陪伴型
- 笔记模板：空白、康奈尔、麦肯锡空雨伞

---

## 二、精简后的扩展建议（聚焦可行性）

### 1. 左侧栏 - 任务区Agent

#### 1.1 题目生成Agent（按难度分）
基于上传的资料生成题目，不同难度：

- **记忆理解型**
  - 单选题：知识点记忆和基础理解
  - 多选题：多个知识点的综合

- **应用分析型**
  - 简答题：用自己的话解释概念
  - 案例分析题：应用资料知识分析场景

#### 1.2 批改评分Agent（按反馈深度分）

- **快速批改型**
  - 客观题自动判分
  - 简单对错反馈

- **详细反馈型**
  - 指出错误点在资料的哪个部分
  - 给出改进建议
  - 提供相关知识点链接

#### 1.3 资料助手Agent（新增）
帮助学生更好地理解上传的资料：

- **资料概览Agent**
  - 自动提取资料的大纲结构
  - 标识核心概念和关键词
  - 生成资料摘要

- **难点解释Agent**
  - 识别资料中的难点
  - 用更简单的语言重新解释
  - 提供类比和例子

### 2. 中间栏 - 自由对话Agent

保持简单，聚焦核心的对话风格（**建议5-6种即可**）：

#### 2.1 核心对话风格

**启发引导型**（引导思考，不直接给答案）
- **苏格拉底式**（已有）：通过层层提问引导
- **费曼式**（新增）：要求学生"用自己的话解释"，检验理解深度

**答疑解惑型**（直接解答问题）
- **标准助教**（已有）：清晰准确，提供标准答案
- **循循善诱型**（已有）：耐心分解，多用类比例子

**挑战型**（训练批判性思维）
- **辩论对手**（已有）：持相反观点，要求学生论证
- **质疑者**（新增）：挑战学生观点，要求提供证据

#### 2.2 知识边界设置（教师可配置）
- **仅限上传资料**：AI只能基于资料库回答，防止学生聊闲天
- **允许适度扩展**：可以补充资料外的背景知识，但会提醒
- **完全开放**：可以联网搜索和跨学科联系

### 3. 中间栏 - 引导学习工作流

保持简洁实用，**建议3-4种核心工作流**：

#### 3.1 已有工作流（保持）
- **费曼学习法**：理解 → 解释 → 回顾 → 简化
- **5E 探究法**：吸引 → 探索 → 解释 → 精制 → 评价
- **BOPPPS模型**：导入 → 目标 → 前测 → 参与 → 后测 → 总结

#### 3.2 建议新增工作流（实用为主）

**SQ3R阅读学习法**（适合资料学习平台）
1. **浏览(Survey)**：快速扫描资料，了解大纲和结构
2. **提问(Question)**：根据标题和关键词提出问题
3. **精读(Read)**：带着问题仔细阅读
4. **复述(Recite)**：合上资料，尝试回忆和复述
5. **复习(Review)**：回顾笔记，做测验巩固

**问题导向学习(PBL)**（适合案例式学习）
1. **问题呈现**：基于资料提出真实问题
2. **分析探究**：在资料中寻找线索
3. **方案设计**：提出解决方案
4. **测试验证**：通过题目或讨论验证
5. **反思总结**：回顾学习过程

### 4. 右侧栏 - 笔记模板（纯文本模板）

保持简洁实用，**建议5-6种**。都是纯Markdown文本模板，不需要UI分区：

#### 4.1 已有模板（保持）
- **空白模板**：完全空白，学生自由发挥
- **康奈尔笔记**：纯文本提示（如：`## 笔记区\n\n## 线索栏\n\n## 总结`）
- **麦肯锡空雨伞**：文本框架（`## 空（现状）\n\n## 雨（原因）\n\n## 伞（解决方案）`）

#### 4.2 建议新增模板（纯文本框架）

**结构化文本**
- **大纲式笔记**：预设多级标题结构
  ```markdown
  # 主题
  ## 第一部分
  ### 知识点1
  ### 知识点2
  ## 第二部分
  ...
  ```

- **问答式笔记**：Q&A框架
  ```markdown
  ## Q1:
  A:

  ## Q2:
  A:
  ```

**学习策略型文本**
- **KWL笔记**：三段式框架
  ```markdown
  ## K - 我已经知道的

  ## W - 我想知道的

  ## L - 我学到的
  ```

- **错题本模板**：结构化记录
  ```markdown
  ## 错题1
  - 题目：
  - 我的答案：
  - 正确答案：
  - 错误原因：
  - 反思：
  ```

### 5. 右侧栏 - 监控Agent

保持简单可配置，**建议3-4种风格**：

#### 5.1 已有监控风格（保持）
- **温柔陪伴型**：适合大多数学生
- **严格督导型**：适合需要强约束的学生

#### 5.2 建议新增监控风格

- **教练型**（新增）：目标导向，阶段性激励
- **静默记录型**（新增）：不打断学生，只记录数据给教师

#### 5.3 干预时机设置（教师可配置）
- **仅关键节点**：完成一个章节、做完测验时
- **中等频率**：每15-20分钟检查一次
- **高频监控**：每5分钟提醒（适合低龄学生）

#### 5.4 触发干预的场景示例
- 同一页面停留超过X分钟 → 提醒"需要帮助吗？"
- 连续3次测验错误 → 建议"要不要重新看一下资料？"
- 长时间没有做笔记 → 提示"记得做笔记哦"

## 四、总结

精简后的体系聚焦在**NotebookLM式学习平台的核心场景**：

**核心价值**：
1. 帮助学生更好地**理解上传的资料**
2. 通过**AI对话**深化理解
3. 用**结构化笔记**整理知识
4. 通过**自测**巩固学习

**模板数量控制**：
- 对话Agent：5-6种
- 学习工作流：3-5种
- 笔记模板：5-6种（纯Markdown文本模板，不需要UI分区）
- 监控风格：3-4种

**设计原则**：
- **简单实用**：每个模板都有明确的使用场景
- **基于资料**：所有Agent都围绕上传的资料展开
- **易于配置**：教师通过简单选择+微调即可使用
- **渐进式增强**：MVP先做核心功能，后续逐步扩展
