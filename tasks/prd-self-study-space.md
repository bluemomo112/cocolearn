# PRD: 通用自学空间（Self-Study Space）

## Introduction

当前系统的自学模式是"教师配置 → 学生使用"的组合（类 NotebookLM）。但教师和成人学习者也有自学需求——他们需要一个不依赖"教师角色"的独立学习空间。

通用自学空间提供两种模式：
- **模式1（人类主导）**：用户自己上传资料、配置学习任务、让 AI 辅助生成内容，类似"自己当老师+学生"
- **模式2（AI托管）**：用户只需说明学习目标，AI 自动检索/生成资料、规划路径、执行"测评→学习→再测评"的自适应循环

两种模式不互斥——用户可以从模式1切换到模式2，也可以在模式2中手动干预。模式2适用于有明确标准化路径的学习场景（如雅思备考、算法刷题、考证），AI 本质上是按预设规则执行+动态调整难度。

**入口**：我的主页新增"自学空间"tab（与"我的课程"、"教学洞察"并列）。产品设计不限定用户身份，未来可扩展至学生端。

## Goals

- 让教师/成人学习者拥有独立的自学空间，无需依赖"教师-学生"角色分离
- 模式1：用户可自主配置资料、任务、个性化设置，获得类 NotebookLM 的自学体验
- 模式2：用户只需声明学习目标，AI 自动规划并执行自适应学习循环
- 两种模式可切换、可融合，不互斥
- 复用现有学生端自学空间的核心组件（三栏布局、AI 对话、笔记等）
- 复用现有教师端配置能力的简化版作为模式1的个性化设置

## User Stories

### 模式选择与入口

#### US-001: 我的主页新增"自学空间"Tab
**Description:** As a 教师, I want to 在工作台看到"自学空间"入口 so that 我可以快速进入自学模式。

**Acceptance Criteria:**
- [ ] 我的主页顶部 tab 栏新增"自学空间"选项，与"我的课程"、"教学洞察"等并列
- [ ] 点击后进入自学空间主页面
- [ ] Tab 图标和文案清晰表达"自学"含义
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

#### US-002: 首次进入时选择学习模式
**Description:** As a 用户, I want to 首次进入时选择"自主配置学习"或"AI帮我规划学习" so that 我可以按自己的需求开始学习。

**Acceptance Criteria:**
- [ ] 首次进入自学空间时展示模式选择界面
- [ ] 两个卡片式选项：模式1"自主配置学习"（自己上传资料、配置任务）、模式2"AI智能规划"（告诉AI你想学什么，AI帮你规划）
- [ ] 选择后进入对应模式的工作区
- [ ] 可在设置中随时切换模式
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

### 模式1：人类主导的自学空间

#### US-003: 自学空间主界面（三栏布局）
**Description:** As a 用户, I want to 在自学空间中看到资料区、AI对话区、笔记区 so that 我可以边看资料边和AI交流边做笔记。

**Acceptance Criteria:**
- [ ] 复用现有学生端三栏布局：左侧资料/任务、中间AI对话、右侧笔记
- [ ] 面板可拖拽调整大小
- [ ] 标题为用户自定义的"学习主题"（非教师配置的课程名）
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

#### US-004: 用户自主上传/管理学习资料
**Description:** As a 用户, I want to 自己上传和管理学习资料 so that 我可以基于自己的资料进行学习。

**Acceptance Criteria:**
- [ ] 左侧面板顶部有"添加资料"按钮
- [ ] 支持上传文档（PDF、Word、PPT）、视频、链接
- [ ] 支持让 AI 根据主题生成资料（输入主题 → AI 生成摘要/大纲）
- [ ] 资料列表可排序、删除
- [ ] 上传的资料自动进入 AI 对话的知识上下文
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

#### US-005: 用户自主创建/管理学习任务
**Description:** As a 用户, I want to 自己创建学习任务或让AI生成任务 so that 我可以有目标地学习。

**Acceptance Criteria:**
- [ ] 左侧面板有"任务"区域，可手动创建任务
- [ ] 可输入描述让 AI 自动生成任务（如"帮我生成5道关于微积分的练习题"）
- [ ] 任务支持完成/未完成状态切换
- [ ] AI 生成的任务支持"重新生成"和"编辑"
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

#### US-006: 个性化设置面板
**Description:** As a 用户, I want to 配置AI的行为和学习偏好 so that AI的辅助更符合我的需求。

**Acceptance Criteria:**
- [ ] 自学空间右上角有"设置"图标按钮
- [ ] 点击后弹出设置面板，包含以下简化版配置项：
  - AI 交互模式选择（自由对话 / 引导学习）
  - AI 提示词自定义（"你希望AI如何辅助你？"）
  - 学习目标描述
  - 知识围栏开关（AI是否只基于上传资料回答）
- [ ] 设置保存后立即生效
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

### 模式2：AI托管的自适应学习

#### US-007: AI托管模式 - 学习目标输入
**Description:** As a 用户, I want to 告诉AI我想学什么 so that AI可以帮我规划学习路径。

**Acceptance Criteria:**
- [ ] 进入模式2后展示简洁的输入界面："你想学什么？"
- [ ] 支持自然语言输入（如"我想准备雅思口语，目标7分"、"刷LeetCode中等难度动态规划题"）
- [ ] 用户可选择知识来源偏好（不限 / 只用维基百科 / 只用学术论文 / 自定义）
- [ ] AI 解析目标后展示确认页：学习主题、预估路径、来源偏好
- [ ] 用户确认后 AI 开始自动规划
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

#### US-008: AI自动生成学习资料与路径
**Description:** As a 用户, I want to AI自动为我准备学习资料和路径 so that 我不需要自己找资料。

**Acceptance Criteria:**
- [ ] AI 根据学习目标自动生成/检索学习资料（按用户配置的来源偏好）
- [ ] 资料自动填充到左侧资料面板
- [ ] AI 生成分阶段学习路径（如"阶段1：基础概念 → 阶段2：练习 → 阶段3：模拟测试"）
- [ ] 学习路径以进度条/阶段卡片形式展示
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

#### US-009: AI自适应测评循环
**Description:** As a 用户, I want to AI自动测评我的水平并调整学习内容 so that 学习始终匹配我的当前水平。

**Acceptance Criteria:**
- [ ] AI 在每个学习阶段结束后自动生成测评题
- [ ] 根据测评结果判断掌握程度（通过 / 需加强 / 未掌握）
- [ ] 未掌握的内容自动补充学习资料和练习
- [ ] 已掌握的内容自动推进到下一阶段
- [ ] 学习进度和能力变化可视化展示
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

#### US-010: 模式切换
**Description:** As a 用户, I want to 在两种模式间切换 so that 我可以灵活调整学习方式。

**Acceptance Criteria:**
- [ ] 自学空间顶部或设置中有模式切换入口
- [ ] 从模式1切换到模式2时，已有资料保留，AI 在此基础上规划
- [ ] 从模式2切换到模式1时，AI 生成的资料和任务保留，用户可手动调整
- [ ] 切换时有确认提示
- [ ] Typecheck passes
- [ ] Verify in browser using dev-browser skill

## Functional Requirements

### 入口与模式选择
- FR-1: 我的主页 tab 栏新增"自学空间"选项，点击进入自学空间
- FR-2: 首次进入展示模式选择界面（自主配置 / AI智能规划），选择后记住偏好
- FR-3: 支持在设置中随时切换模式，切换时保留已有数据

### 模式1：人类主导
- FR-4: 自学空间采用三栏布局（资料/任务 | AI对话 | 笔记），面板可拖拽调整
- FR-5: 用户可上传文档（PDF/Word/PPT）、视频、链接作为学习资料
- FR-6: 用户可让 AI 根据主题生成学习资料（摘要/大纲）
- FR-7: 用户可手动创建学习任务，或输入描述让 AI 自动生成任务
- FR-8: AI 生成的任务支持重新生成和编辑
- FR-9: 上传的资料自动纳入 AI 对话的知识上下文
- FR-10: 个性化设置面板包含：AI交互模式、提示词自定义、学习目标、知识围栏开关

### 模式2：AI托管
- FR-11: 用户输入自然语言学习目标，AI 解析并展示确认页
- FR-12: 用户可配置知识来源偏好（不限 / 指定来源）
- FR-13: AI 自动生成/检索学习资料并填充到资料面板
- FR-14: AI 生成分阶段学习路径，以进度条/阶段卡片展示
- FR-15: 每个阶段结束后 AI 自动生成测评题
- FR-16: 根据测评结果自动调整：未掌握→补充练习，已掌握→推进下一阶段
- FR-17: 学习进度和能力变化可视化展示

## Non-Goals (Out of Scope)

- 不做社交/协作功能（如分享学习空间、多人协作笔记）
- 不做付费/订阅相关功能
- 不做移动端适配（本期只做 Web 端）
- 模式2不做通用的"任意领域"自适应学习——仅支持有明确标准化路径的场景
- 不做学习数据的跨空间聚合分析
- 不做与现有"教师配置→学生使用"模式的数据互通

## Design Considerations

- **复用现有组件**：三栏布局、AI对话、笔记编辑器、资源上传等均复用学生端 workbench 组件
- **设置面板**：复用教师端 note-config 的简化版，去掉"课程"相关概念，保留 AI 配置核心项
- **模式选择界面**：参考 NotebookLM 的首页风格，两个大卡片，简洁明了
- **模式2的学习路径**：参考 Duolingo 的阶段式进度展示，但更简洁
- **整体风格**：与现有系统保持一致，使用相同的设计系统和组件库

## Technical Considerations

- **路由**：新增 `/teacher/self-study` 路由（或在教师 page.tsx 中作为 tab 内容）
- **数据存储**：自学空间的资料、任务、设置需要独立的数据结构，不与课程数据混用
- **AI 接口**：模式1复用现有 chat API；模式2需要新增"学习规划"和"自适应测评"的 AI 接口
- **模式2的知识检索**：需要对接第三方知识源（搜索引擎 API / 学术库 API），按用户偏好配置
- **状态管理**：使用 Zustand store 管理自学空间状态（当前模式、资料列表、任务列表、设置等）
- **组件复用**：从 student/workbench 中提取可复用组件，避免代码重复

## Success Metrics

- 教师可在 3 步内从工作台进入自学空间并开始学习
- 模式1：用户可在 5 分钟内完成"上传资料 → 配置设置 → 开始AI对话"的完整流程
- 模式2：用户输入学习目标后，AI 在 30 秒内生成学习路径和首批资料
- 模式切换时数据零丢失
- 自学空间的 AI 对话质量不低于现有学生端

## Open Questions

1. 模式2的"知识来源偏好"具体支持哪些第三方源？需要调研可用的 API
2. 模式2的自适应算法具体采用什么策略？（如 IRT 项目反应理论、简单的正确率阈值等）
3. 自学空间的数据是否需要持久化到服务端？还是先用本地存储？
4. 未来扩展到学生端时，入口放在哪里？是否需要权限控制？
5. 模式2是否需要预设一些"学习模板"（如"雅思备考模板"、"算法刷题模板"）来降低 AI 规划的不确定性？
